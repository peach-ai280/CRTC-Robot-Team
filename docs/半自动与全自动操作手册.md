# 半自动 / 全自动 操作手册

> 一句话：**SELECT 键切三档，手动 → 半自动 → 全自动。**
> 全自动是在半自动之上叠的一层"自动调度"，没有重写抓取动作。
> 所以顺序必须是：**先把半自动调稳，再上全自动。**

---

## 一、三档模式

| 档位 | 串口打印 | 谁在做决策 | 什么时候用 |
|---|---|---|---|
| **手动** `MANUAL` | `mode=man` | 操作手全程 | 检录、走位、救场 |
| **半自动** `SEMI-AUTO` | `mode=semi` | 人按一个键，车完成一串动作 | **中期考核主力** |
| **全自动** `FULL-AUTO` | `mode=full` | 车自己找块、自己抓 | 练熟之后再说 |

**切换**：按一下 SELECT，循环 `手动 → 半自动 → 全自动 → 手动…`
切档时会**先中止正在跑的动作**再换，不会"带着动作换档"。

---

## 二、半自动：五个一键宏

半自动档下，按一次键，车自己完成一串动作，**有硬超时、可被摇杆打断**。
决策权在操作手——这就是它算半自动而不是全自动的原因。

| 按键 | 动作 | 成功时会看到 |
|---|---|---|
| **○** | 地面取块：放铲 → 靠拢 → 对中 → 夹 → 抬 → 入仓 → 退一步 | 方块进储仓 |
| **△** | 挑物资架上的黄色能量核心 | 黄块被撬下来掉进兜里 |
| **□** | 洞窟探杆取块 | 块从洞里被勾出来 |
| **×** | 一键贴边横移 | 车贴住场地边框 |
| **L2** | 视觉辅助对位（需 `USE_VISION=1`） | 车自己转向方块再夹 |

**打断**：宏跑的时候**推一下摇杆**，立刻中止并交还控制权。
这是安全设计——看到要撞墙就推摇杆，别等它跑完。

**L1** 任何时候都能按：全部机构收起（检录姿态）。

### 半自动要练到什么程度才算"稳"

- 地面取块 **10 次成功 8 次以上**
- 取一个块的全过程 **不超过 6 秒**
- 从没出现过"夹起来了又掉"

达不到就先别碰全自动——全自动只是自动按这个键，键本身不准，自动一百遍也没用。

---

## 三、全自动：它到底在干什么

全自动 = **巡游找块 + 自动按 ○ + 抓完换地方继续**。

```
进档 → 预备 2 秒（机构收起，给你走开的时间）
    → 蛇形巡游（前进一段、横移换道、再前进…走完 4 条道自动掉头回扫）
    → 撞上对中限位（或视觉看到方块）
    → 靠拢 → 触发「地面取块」宏
    → 抓完收机构 + 退一步
    → 继续巡游，直到拿满 3 个 / 连败 3 次 / 跑满 4 分钟
```

### 三道保险（别乱改）

| 保险 | 参数 | 触发后 |
|---|---|---|
| 总时长上限 | `AUTO_TOTAL_LIMIT_MS = 240000` | 无条件停车（一局 5 分钟，留 60 秒余量） |
| 连败上限 | `AUTO_FAIL_LIMIT = 3` | 停车等人接管，不在空地上反复空抓 |
| 拿够就收工 | `AUTO_MAX_PICK = 3` | 储仓只有 3 格，别贪 |

### 全自动的退出方式（三种，都会退回半自动）

1. **推一下摇杆** —— 立刻接管
2. **按 START** —— 急停
3. **跑到 DONE** —— 拿满 / 连败 / 超时，自己停

跑到 DONE 之后想再来一轮：按 **○** 重启。

## 四、参数怎么标（在 config.h 里）

### 第一步：先标半自动（第 4 节 `AUTO_*`）

| 参数 | 现象 → 怎么改 |
|---|---|
| `AUTO_APPROACH_SPEED` | 靠拢太慢 → 调大；把块撞飞 → 调小 |
| `AUTO_APPROACH_TIMEOUT` | 明明对准了却报超时 → 调大 |
| **`AUTO_PICK_HARD_TIMEOUT`** | ⚠ **夹起来了却报失败** → 一定是这个太小。要大于取块序列的实际耗时，实测约 3970ms，现在设 5000 |

> 这个坑我踩过：序列要 3970ms，超时写 3000ms，结果**每一次取块都判定失败**，
> 夹起来又丢掉。模拟器验证时才抓到。你如果看到"夹起来了又掉"，先查这个。

### 第二步：再标全自动（第 4b 节）

把车放到场地上，切到全自动，掐表看它走得多远：

| 现象 | 改哪个 |
|---|---|
| 撞墙了 | `AUTO_CRUISE_FWD_MS` 调小 |
| 一趟只扫了半场 | `AUTO_CRUISE_FWD_MS` 调大 |
| 换道间距太大、漏块 | `AUTO_CRUISE_STRAFE_MS` 调小 |
| 换道太密、原地蹭 | `AUTO_CRUISE_STRAFE_MS` 调大 |
| 起步就冲、人来不及躲 | `AUTO_FULL_ARM_DELAY_MS` 调大 |

## 五、⚠ 关于规则，有句实话

**半自动不是强制项。** 我逐条核对过手册 4.1 的基础功能清单，没有"必须完成半自动"这一条，
`docs/08_半自动与视觉.md` 里有核对过程。

**全自动需要组委会现场认定**——不是你说全自动就是全自动。
所以别把宝押在这上面：中期考核的主力是**手动 + 半自动**，
全自动是练熟之后锦上添花的。

这也是为什么我说"先半自动再全自动"——顺序反了，两头都拿不到分。

## 六、现场应急速查

| 现象 | 第一动作 |
|---|---|
| 车不动 | 按 START 急停 → 看串口电压 → 检查 `nSLEEP` |
| 宏卡住不动 | 推一下摇杆（会中止宏） |
| 全自动乱跑 | 推摇杆接管 → 按 SELECT 退回半自动 |
| 舵机"吱吱"叫 | 立刻断电，那个舵机超行程了 |
| 夹起来了又掉 | `AUTO_PICK_HARD_TIMEOUT` 太小 / 夹爪角度不够 |
