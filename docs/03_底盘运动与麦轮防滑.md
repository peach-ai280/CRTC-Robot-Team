# 底盘运动与麦轮防滑

## 功能描述

让两个 PS2 摇杆变成四个轮子的转速，并且**在白色地胶上不打滑、在坡上不溜车**。
这是全车技术含量最高的一块，也是我们在 09-23 ~ 09-26 连着改了四版的地方。

代码位置：`firmware/Core/Src/mecanum.c`（解算 + 防滑）、`motor.c`（输出层）、
参数全部集中在 `firmware/Core/Inc/config.h`。

---

### 2026-09-19 · 麦轮运动学：纸上先推一遍

坐标约定（写死在 `mecanum.h` 里，全工程统一）：

```
x = 车头方向（前为正）
y = 车体左侧（左为正）
ω = 逆时针为正（俯视）
轮序：0=LF 左前  1=RF 右前  2=LB 左后  3=RB 右后
```

X 型麦轮的逆解（推导过程见代码注释）：

```
w_LF = ( vx - vy - (a+b)·ω ) / R
w_RF = ( vx + vy + (a+b)·ω ) / R
w_LB = ( vx + vy - (a+b)·ω ) / R
w_RB = ( vx - vy + (a+b)·ω ) / R
```

其中 a = 半轴距 = 0.090m，b = 半轮距 = 0.068m，R = 轮半径 = 0.030m。

**我们先用三个特例自检，再写代码**（这一步救了我们至少半天）：

| 动作 | 期望 | 代入公式 |
|---|---|---|
| 纯前进 vx>0 | 四轮同号同值 | 四轮都是 +vx/R ✓ |
| 纯左移 vy>0 | 对角同号 | LF=−、LB=+、RF=+、RB=− ✓ |
| 纯逆时针 ω>0 | 左轮退右轮进 | LF=−、LB=−、RF=+、RB=+ ✓ |

正解（给将来的里程计用）也一起写了，先用不上但保留接口：

```
vx = ( w1 + w2 + w3 + w4 ) · R / 4
vy = (−w1 + w2 + w3 − w4 ) · R / 4
ω  = (−w1 + w2 − w3 + w4 ) · R / (4·(a+b))
```

### 2026-09-21 · 单电机先转起来：确认 PWM 频率

用 TIM4 四通道输出 PWM。**频率定为 10kHz**，理由：

- 太低（< 5kHz）：电机有啸叫，而且低速时转矩脉动明显
- 太高（> 20kHz）：DRV8833 的开关损耗上升，便宜模块会发热
- 10kHz 是个不啸叫、也不发热的甜点

CubeMX 配置：`TIM4` PSC = 0、ARR = 7199 → 72MHz / 7200 = 10kHz。
改了 CubeMX 的分频要同步改 `motor.c` 里的 `MOTOR_PWM_PERIOD`，否则占空比全部错。

### 2026-09-22 · 四个电机全转：踩到 nSLEEP 悬空

**现象**：PWM 波形用万用表量到了（有电压变化），但电机一动不动。

**排查**：量 DRV8833 的 `nSLEEP` 引脚 —— **悬空**。
DRV8833 的 nSLEEP 是低电平休眠，几块钱的模块经常把它引出来但不默认上拉。
悬空时芯片处于随机状态，多数时候就是休眠。

**解决**：飞一根线把 nSLEEP 接到 VCC（我们接的是改造后的 5V，见 `04` 板块）。

> 这个坑的特点是"看起来像驱动烧了"，新手很容易直接换模块。
> 我们把它写进了 `硬件接线与焊接指南.md` 的故障速查表第一条。

### 2026-09-23 · 麦轮解算 v1：横移时车自己转圈

**现象**：推纯横移（左摇杆只往左右打），车确实往左走，但**同时在缓慢自转**，
走 1 米能偏 30° 以上。推纯前进反而正常。

**原因**：我们第一版对每个轮单独做了限幅：

```c
// v1（错）
for (i=0;i<4;i++) if (wheel[i] > 1.0f) wheel[i] = 1.0f;
```

纯横移时四轮的**绝对值相等**，所以看不出问题。
但因为有 `SPEED_GAIN_STRAFE = 0.80` 而 `SPEED_GAIN_YAW = 0.45`，
只要操作手的手有一点点抖（摇杆不可能完全只动一个轴），
ω 分量就会让某些轮先撞到 100% 上限被截掉，
**截断之后四轮的合成速度矢量方向就不再是纯横移了** —— 于是车画弧。

### 2026-09-24 · 矢量归一化限幅：本周期最重要的一次改动

**改法**：算出四轮绝对值的最大值，如果超过 1 就**整体等比缩放**：

```c
// v2（对）
float mx = max(|w[0]|,|w[1]|,|w[2]|,|w[3]|);
if (mx > 1.0f) { float k = 1.0f/mx; for(i) w[i] *= k; }
```

这样速度矢量的**方向严格保持**，只是整体变慢一点。
慢一点是可接受的，方向错了是不可接受的 —— 尤其在 2400×2400 的场地里，
方向错 10° 走 2 米就偏 350mm，会直接错过一个方块。

**效果**：横移偏航从 30°/m 降到 **< 3°/m**【待回填：实测】。

这个处理几乎不花成本（6 行代码），但它是"新手车"和"能打的车"的分水岭。
我们把它写进代码注释时特意写了长注释，因为**这一步最容易被漏**。

### 2026-09-25 · 死区补偿：解决"小油门不动、半油门窜"

**现象**：摇杆推 20% 车不动，推到 50% 突然往前窜一下。

**原因**：TT 马达 + DRV8833 有**静摩擦死区**。占空比低于约 18% 时电机转矩克服不了
齿轮箱静摩擦，完全不转；一旦超过，车就以一个不小的初速度起步。这是典型的开环系统特性。

**改法**：把 0~1 的速度映射到 `DEADZONE ~ 1` 的占空比：

```c
duty = MOTOR_DEADZONE + mag * (1.0f - MOTOR_DEADZONE);
```

`MOTOR_DEADZONE` 默认 0.18，实测范围 0.12 ~ 0.26（取决于地面脏不脏、电池电量）。

**副作用与处理**：加了死区之后，速度为 0 附近会有阶跃。
我们在 `chassis_ramp()` 里加了 `if(|cur| < 0.001) cur = 0`，消掉 0 附近的抖动。

### 2026-09-26 · 加速度斜坡：起步不打滑了

**现象**：满油门起步的瞬间，四个轮子空转"吱"一下，车反而慢半拍才动。

**分析**：麦轮的辊子是塑料的，和地胶的接触是**小面积线接触**，
比普通橡胶轮容易打滑得多。突加占空比 → 瞬时转矩突破静摩擦 → 打滑 →
轮子转得比车快 → 车反而没怎么动。

**改法**：限制速度变化率（斜坡限幅），让轮子始终工作在滚动摩擦区：

```c
float lim = (加速? ACC_UP : ACC_DOWN) * dt;
d = clamp(target - cur, -lim, +lim);
cur += d;
```

加速和减速用**不同的上限**（`ACC_UP = 3.0`、`ACC_DOWN = 6.0` / 单位：归一化速度每秒）。
起步慢一点、刹车快一点，既防滑又符合操作直觉。

**调参手感对照**（写进 config.h 了）：

| 现象 | 改哪个 | 方向 |
|---|---|---|
| 起步轮子空转、车抖 | `CHASSIS_ACC_UP` | 调小 |
| 起步肉、反应慢 | `CHASSIS_ACC_UP` | 调大 |
| 松摇杆滑行很远、冲过目标 | `CHASSIS_ACC_DOWN` | 调大 |

另外加了**起步助力（kick）**：从静止跨过阈值时额外叠 12% 占空比，120ms 内线性衰减。
这是为了克服静摩擦的"那一下"，比单纯调大死区温和得多 —— 死区调大会让低速控制变粗糙。

### 2026-09-24（补）· 高速限自转：防止甩尾

**现象**：边前进边自转时，整车会"甩"一下，方向突然变。

**原因**：麦轮靠四轮的差速合成转向。高速行进时叠加自转，
某些轮会进入反向大电流区，瞬时打滑 → 合成矢量突变。

**改法**：把 ω 的上限做成线速度的函数：

```c
|ω| ≤ YAW_LIMIT_BASE − YAW_LIMIT_K · |v线|
```

`BASE = 0.90`、`K = 0.60`：静止时可以全速自转（0.90），
全速前进时只剩 0.30 的自转能力。这符合物理直觉，也符合比赛实际 ——
高速冲的时候本来也不该大幅转向。

### 2026-10-12 · 电池电压补偿：两局之间速度要一致

**现象**：同一套参数，刚充好电时车跑得挺好，第二局（电池掉到 7.0V 左右）明显变慢，
操作手会觉得"车坏了"，其实就是电压掉了。

**改法**：测电池电压，占空比按比例补回来：

```c
g_vcomp = VBAT_NOMINAL / vbat;       // 7.40 / 7.00 = 1.057
duty *= g_vcomp;                      // 上限 VBAT_COMP_MAX = 1.25
```

分压电路是 20k + 10k（比值 3.0），接 PB1 / ADC1_IN9，
采样周期 200ms 并做了一阶滤波（α=0.2），避免电机启停时的电压毛刺导致占空比抖动。

同时加了低电压报警：低于 6.60V 时 LED 从 1Hz 慢闪变成 5Hz 快闪 + 蜂鸣器响。
**18650 过放会永久损坏**，这个报警是保护电池的，不是装饰。

### 2026-10-14 · 坡道防滑撑地块（进阶功能）

2 号机在地面活动，遇到坡道（26.6°）时麦轮会打滑。
我们加了一个 SG90 驱动的"撑地块"：

- 平地上收起，离地 15mm
- 上坡前放下，橡胶垫（自行车内胎剪的）压地

原理是**增加正压力**从而提高最大静摩擦。要注意的是它不能"顶起车"
（那会让驱动轮离地反而更糟），而是**轻触地面提供额外摩擦**。

`22_ramp_anchor.stl` + `config.h` 里的备用舵机角度控制。

### 为什么我们没有做编码器闭环

**没有做，但要说清楚为什么**（这是答辩时会被问的）：

1. 官方物资表里的 TT 马达是**单轴 1:48 无编码器款**，
   要闭环得另外买带编码器的马达（约 +12 元/个 × 8 = 96 元），超出成本预算。
2. 编码器要占用 TIM2/TIM3 的输入捕获通道，而我们的 TIM2 已经给舵机了。
3. 时间上，新手在一周内调通 4 路 PID 的风险很高。

**但代码里留了口子**：`config.h` 的 `USE_ENCODER` 打开后 `motor.c` 会切到 PID 闭环，
`USE_IMU` 打开后可以做航向保持。如果中期考核后有时间和预算，这是第一个要补的升级。
