# 电源、硬件与焊接

## 功能描述

把一块 7.4V 电池分配成"电机动力"和"5V 逻辑/舵机"两路，并且满足手册对
**唯一供电模块**、**无线继电器遥控断电**的强制要求。完整引脚表与焊接点位见
`docs/硬件接线与焊接指南.md`，本板块只记录决策过程与踩过的坑。

---

### 2026-09-18 · 电源树设计：先读规则再动手

手册 3.3.2 里最容易理解错的一句：

> 每台机器人仅允许安装 1 个供电模块，且供电模块额定电压不超过 7.4V。
> 供电模块定义为**有且仅有一个输出接口**的供电装置。

我们的理解（并在 Q&A 文档里确认口径）：

- 2 节 18650 **串联** → 标称 7.4V、满电 8.4V → 符合"额定电压 ≤ 7.4V"
- 电池盒自带的那**一对线**就是唯一输出接口
- 所有分支必须在电池**之后**分，不能在电池盒里做成两路独立输出

电源树：

```
18650×2 (7.4V)
   └─ 无线继电器 (IN 接电池 / OUT 接整车)
        └─ 节点 P
             ├─ DRV8833 ×2 的 VM        (7.4V 直供)
             └─ Mini 降压 → 5V
                  ├─ STM32 的 5V 脚
                  ├─ MG995 ×1
                  └─ SG90 ×3
```

### 2026-09-19 · 继电器取电位置：一个能直接毁掉整局的坑

我们一开始把继电器串在了电池和整车之间，线圈也从 OUT 侧取电。
按断电遥控器的瞬间，继电器自己也没电了 —— **再也合不上，车永久断电**。

正确接法：`IN+ / IN-` 接**电池直出**，`OUT+ / OUT-` 接整车。
继电器控制的是"整车"，不是"自己"。这条写进了接线指南的 1.3 节。

另外记录规则细节：手册说检录时会检测遥控断电功能，**检测无误后参赛队需要向裁判上交断电遥控器**，
比赛结束后取回。所以继电器和遥控器要在检录前就装好、测好，别指望现场调。

### 2026-09-22 · DRV8833 逻辑电源改造（必做）

DRV8833 芯片的 `VCC`（逻辑电源）规格是 **1.8 ~ 7V**，`VM`（电机动力）可以到 10.8V。
我们电池满电 8.4V。

用万用表蜂鸣档量了几块钱的红色模块，发现 `VCC` 和 `VM` **是通的** ——
厂家用一颗 0Ω 电阻把 VCC 直接接到 VM 上了。这意味着长期运行时 VCC 会被 8.4V 超规格供电。

**改造**：切断 VCC 与 VM 之间的铜箔（或拆掉那颗 0Ω），把 VCC 单独飞线到 5V。
改完再量一次确认两者不通。

> 这个改造 5 分钟能做完，但不做的话驱动芯片在比赛中后期失效的概率不低。
> 而且芯片失效的表现往往是"电机时转时不转"，排查起来非常痛苦。

### 2026-09-29 · MG995 上电：5V 塌陷导致单片机复位

**现象**：单独给 SG90（小舵机）供电一切正常；一把 MG995 接上、让它转动，
STM32 立刻复位（串口输出的 boot 信息重新打一遍）。

**测量**：MG995 启动/堵转电流实测能到 **1.2A**（用钳形表在 5V 线上量的，
万用表串进去会因为内阻太大测不准）。

**原因链**：
1. 杜邦线线芯只有约 0.2mm²，1A 电流下的压降非常可观
2. Mini 降压模块瞬态响应跟不上，5V 瞬间跌到 4.3V 以下
3. STM32 板载 AMS1117-3.3 的输入低于 4.5V 就撑不住 3.3V 输出 → 单片机复位

**解决（按做的顺序）**：

| # | 措施 | 效果 |
|---|---|---|
| 1 | 在 5V 汇流点并 **470μF/16V 电解 + 0.1μF 瓷片** | 复位次数明显减少，但没根治 |
| 2 | 5V/GND 主干换成 **0.5mm² 硅胶线**（弃用杜邦线做电源） | 基本解决 |
| 3 | `SERVO_SPEED_DPS` 从 240 降到 200，限制舵机动作速度 | 峰值电流下降 |
| 4 | `arm.c` 改成**串行序列器**，同一时刻只有一个舵机在动 | 彻底解决 |

第 4 条是设计层面的改动，值得展开说一下：

> 我们原来的 `Arm_Start()` 是"同时给所有舵机下发目标角度"。
> 四个舵机一起启动 = 峰值电流叠加。改成序列器后，
> 一个舵机到位 → 等 N 毫秒 → 再动下一个。
> 代价是一个完整取块动作从 0.6s 变成约 1.2s。
> **我们接受这个代价**：比赛 5 分钟，慢 0.6s 不影响拿几个块；
> 但现场复位一次，可能直接丢掉一整局。

### 2026-09-30 · 转接板：从面包板到洞洞板

前期用面包板验证功能，但手册 3.3.3 明确写：

> 线路设计时建议采用集成电路板的方式，单一使用杜邦线易出现连线脱落的情况。

而且结构强度检测是从 180mm 高处**自由跌落** —— 面包板上的杜邦线必掉。

于是花了一个晚上焊了一块 7×9cm 洞洞板：

- STM32 用 **2×20 排母**插装（方便拔下来烧录）
- 电机 8 路（PWM×4 + DIR×4）、舵机 4 路、PS2 6 路、限位开关 2 路全部用排针引出
- 5V 和 GND 在板背面用 0.5mm² 导线做主干（洞洞板的铜箔带不动 1.5A）
- 所有 GND 用焊锡堆连成一片

焊完的**检查清单**（逐条做的）：

1. 万用表蜂鸣档逐点量通断
2. 放大镜检查排针密集处有没有锡桥
3. 轻拽每根线看会不会掉
4. 空载上电量 5V 是否为 5.0 ± 0.2V

### 2026-10-12 · 电压检测分压与低电压报警

分压电路 20kΩ + 10kΩ（比值 3.0），满电 8.4V 时 PB1 上是 2.8V < 3.3V 安全。
`config.h` 的 `VBAT_ADC_DIV = 3.0` 对应这个比值。

报警阈值定在 **6.60V**。两节 18650 串联的安全放电下限一般是 6.0V（单节 3.0V），
6.6V 留了余量，响的时候就该换电池了。
