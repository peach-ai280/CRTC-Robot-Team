# 现场调参指南

> 这份文档是给**比赛当天 / 前一天**用的。按从上到下的顺序调，**不要跳步**，
> 因为后面的参数依赖前面的标定结果。
> 所有参数都在 `firmware/Core/Inc/config.h`，改完重新编译烧录即可，不用动任何 `.c`。

---

## 0. 调参前的三条铁律

1. **一次只改一个参数。** 同时改三个，出问题你不知道是谁的锅。
2. **每次改完在同样的地面、同样的电量下测。** 地胶脏了、电池掉压都会让参数漂移。
3. **架空优先。** 电机方向、舵机角度这些能在架空的车上调的，就不要落地调。
   落地调 = 车随时可能窜出去撞墙。

---

## 1. 标定顺序总览

```
第 0 步  ROBOT_ID / 确认烧的是哪台车
第 1 步  MOTOR_x_DIR     四个轮的转向
第 2 步  MOTOR_DEADZONE  死区
第 3 步  MOTOR_LEFT/RIGHT_TRIM  直线跑偏
第 4 步  CHASSIS_ACC_*   加速度斜坡（防滑）
第 5 步  SPEED_GAIN_*    速度手感
第 6 步  舵机角度（用方向键在线标定）
第 7 步  AUTO_* 时间参数（半自动宏）
第 8 步  CHASSIS_V_MAX / W_MAX（有余力再做）
```

---

## 2. 第 1 步：轮转向（最基础，也是最容易搞反的）

**方法**：架空 → 推左摇杆向前 → 四个轮都应该朝"让车前进"的方向转。

麦轮的正确转向（俯视，车头朝上）：

| 轮 | 前进时应转 |
|---|---|
| 左前 LF | 逆时针（俯视） |
| 右前 RF | 顺时针 |
| 左后 LB | 逆时针 |
| 右后 RB | 顺时针 |

**哪个轮反了，就把 `config.h` 里对应的 `MOTOR_x_DIR` 从 `1` 改成 `-1`（或反过来）。**

```c
#define MOTOR_LF_DIR             1
#define MOTOR_RF_DIR            -1
#define MOTOR_LB_DIR             1
#define MOTOR_RB_DIR            -1
```

> **不要去改线！** 换线意味着你要重新做接插件，现场来不及。
> 改一个数字 30 秒搞定，效果完全一样。

如果**四个轮都转、但车往反方向走**（前后反了 / 左右反了 / 转向反了），
改这三个：

```c
#define FORWARD_SIGN             1   // 前后反了改 -1
#define STRAFE_SIGN              1   // 横移反了改 -1
#define YAW_SIGN                 1   // 自转反了改 -1
```

---

## 3. 第 2 步：死区

**测试方法**：缓慢推摇杆，找到"车刚开始动"的那个摇杆位置。

| 现象 | 判断 | 动作 |
|---|---|---|
| 推到 40% 才动，一动就窜 | 死区太小 | `MOTOR_DEADZONE` 调大 |
| 推一点点就猛地窜出去 | 死区太大 | 调小 |
| 从 15% 开始平滑加速 | 合适 | 保持 |

默认值 0.18。实测范围：**干净地胶 0.12 ~ 0.20；脏地胶/低电量 0.20 ~ 0.28**。

⚠️ 四个轮的死区其实不一样（TT 马达个体差异），但 `config.h` 只有一个全局值。
折中办法：取**最大值**，然后用第 3 步的 TRIM 补偿剩下的不对称。

---

## 4. 第 3 步：直线跑偏（TRIM）

**测试方法**：在空地上画一条 2m 直线，全油门直行，看偏多少。

- 往**左**偏 → 说明右边轮子快 → `MOTOR_RIGHT_TRIM` 调小（如 0.95）
- 往**右**偏 → `MOTOR_LEFT_TRIM` 调小

```c
#define MOTOR_LEFT_TRIM          1.00f
#define MOTOR_RIGHT_TRIM         1.00f
```

每次调 0.02，别一次调太多。2m 内偏差 < 50mm 就可以了，
再精确下去在这个场地里没有意义。

---

## 5. 第 4 步：加速度斜坡（防滑核心，现场最常改的）

| 现象 | 改哪个 | 方向 |
|---|---|---|
| 起步轮子空转、车抖、"吱"一声 | `CHASSIS_ACC_UP` | **调小**（3.0 → 2.0 → 1.5） |
| 起步肉、反应慢、跟不上操作 | `CHASSIS_ACC_UP` | 调大（3.0 → 5.0） |
| 松摇杆滑行很远、冲过目标 | `CHASSIS_ACC_DOWN` | **调大**（6.0 → 10.0） |
| 刹车太猛，方块从储仓滚出来 | `CHASSIS_ACC_DOWN` | 调小（6.0 → 4.0） |
| 边走边转时甩尾 | `YAW_LIMIT_K` | 调大（0.60 → 0.80） |
| 高速时想转转不动 | `YAW_LIMIT_BASE` | 调大（0.90 → 1.20） |

**现场应急配方**（如果地面特别滑）：

```c
#define CHASSIS_ACC_UP           1.5f   // 慢起步
#define CHASSIS_ACC_DOWN         8.0f   // 但要停得住
#define MOTOR_KICK_DUTY          0.20f  // 起步助力加一点
#define SPEED_GAIN_FORWARD       0.70f  // 整体降速
```

**场地变脏 / 电池没电时**，第一反应应该是降速度而不是加死区。
降速解决的是根本（摩擦不够），加死区只是在掩盖症状。

---

## 6. 第 5 步：速度增益

```c
#define SPEED_GAIN_FORWARD       0.85f
#define SPEED_GAIN_STRAFE        0.80f
#define SPEED_GAIN_YAW           0.45f
```

| 现象 | 动作 |
|---|---|
| 爬不上坡、追不上对手 | `FORWARD` 调大（0.85 → 0.95） |
| 一给油门就抬头/打滑 | `FORWARD` 调小 |
| 横移明显比直行慢 | `STRAFE` 调大（麦轮横移效率天生低，可以比 FORWARD 大） |
| 原地自转打滑 | `YAW` 调小（0.45 → 0.35） |

---

## 7. 第 6 步：舵机角度（用在线标定，别在代码里猜）

**这是最省时间的一条**：不用改代码、不用重新烧录。

1. 用 USB-TTL 把串口接到电脑（115200）
2. 按 PS2 的 **↑ / ↓** 微调大臂，串口会打印 `arm=xx`
3. 按 **← / →** 微调夹爪，串口打印 `grip=xx`
4. 按 **L2 / R2** 微调前铲（没开视觉时），串口打印 `scoop=xx`
5. 调到满意的角度 → **把数字抄进 `config.h`** → 重新编译烧录固定下来

```
V=7.82 | btn=0000 | L(   0,   0) R(   0,   0)
  cmd v=(+0.00,+0.00) w=+0.00 | wheel +0.00 +0.00 +0.00 +0.00
  duty 0.00 0.00 0.00 0.00 | arm=25 grip=30 scoop=60      ← 这三个就是当前角度
  limit L0 R0 | macro=0 step | mode=semi
```

**每组角度都对应一个物理位置**，调的时候按这个顺序：

| 顺序 | 姿态 | 调到什么程度 |
|---|---|---|
| 1 | `SERVO_ARM_STOW`（收起） | 机构最低矮、不超出车顶、跌落时不突出 |
| 2 | `SERVO_SCOOP_DOWN`（铲贴地） | 铲前缘刚好离地 1~2mm，不蹭地 |
| 3 | `SERVO_SCOOP_TRAVEL`（行驶位） | 离地 15mm，过桥/上坡不磕 |
| 4 | `SERVO_ARM_GROUND`（地面取块） | 夹爪张开后能包住地面上的方块 |
| 5 | `SERVO_GRIP_HOLD_CUBE`（夹白块） | 夹紧 **30mm** 方块（V1.4），能提起来不滑 |
| 6 | `SERVO_ARM_STEP`（台阶/焦点取块） | 夹爪对齐 150mm 台阶面或焦点平台上方 |
| 7 | `SERVO_ARM_LIFT`（举起） | 方块底部高过储仓挡板 |
| 8 | `SERVO_ARM_RACK`（挑物资架） | 挑杆到最高，能够到 250mm 高处 |

⚠️ **舵机"吱吱"抖 = 脉宽超行程**，把 `SERVO_PWM_MIN_US` / `MAX_US` 往中间收（每次收 30μs）。

## 8. 第 7 步：半自动宏的时间参数

**这些是盲走参数，必须在实车上重标。** 标定的唯一办法是"跑 10 次，数成功几次"。

| 参数 | 含义 | 标定方法 |
|---|---|---|
| `AUTO_APPROACH_SPEED` | 靠拢速度 | 从 0.25 开始往上试，找到成功率 × 节奏的最优点 |
| `AUTO_APPROACH_TIMEOUT` | 靠拢超时 | 设为"正常靠拢时间的 1.5 倍" |
| `AUTO_GRIP_SETTLE_MS` | 夹紧等待 | 舵机从张开到夹紧的实际时间 + 50ms |
| `AUTO_LIFT_SETTLE_MS` | 抬起等待 | 同上 |
| `AUTO_STORE_SETTLE_MS` | 入仓等待 | 同上 |
| `AUTO_BACKUP_SPEED` / `MS` | 后退确认 | 退 100~150mm 就够 |

**判断宏失败原因的方法**（串口会打 `[MACRO] aborted` 或超时）：

| 现象 | 原因 | 改什么 |
|---|---|---|
| 车一直慢慢往前走，超时 | 限位开关没触发 | 检查摆杆是否被卡住；方块是不是被推走了 |
| 车停下但没夹紧 | 机构序列卡住 | 加大 `*_SETTLE_MS` |
| 夹到方块但提不起来 | 夹爪太松 | `SERVO_GRIP_HOLD_CUBE` 调大角度；贴硅胶垫 |
| 方块进了铲但没进储仓 | 前铲兜送角度不够 | `SERVO_SCOOP_UP` 角度调小（兜得更高） |

## 9. 第 8 步（有余力再做）：V_MAX / W_MAX

```c
#define CHASSIS_V_MAX            0.60f   // m/s  满油门直线速度
#define CHASSIS_W_MAX            4.00f   // rad/s 满油门自转速度
```

标定方法：地上贴胶带量 2m，全油门直行掐表；原地自转掐表转 3 圈。

这两个数只影响"**横移/自转混合时**"的比例。
不填准也能跑，但填准之后斜着走才不会莫名其妙画弧。
**如果时间紧，这一步可以跳过。**

## 10. 现场症状速查（打印出来贴在操作台上）

| 现象 | 第一反应 | 具体动作 |
|---|---|---|
| 车不动，PWM 有输出 | nSLEEP 悬空 | 量 DRV8833 的 nSLEEP 是否为高 |
| 车往一边偏 | 轮死区不对称 | step 3 调 TRIM |
| 起步打滑 | 加速度太快 | `CHASSIS_ACC_UP` → 2.0 |
| 横移时自己转圈 | 归一化没生效 or 尺寸填错 | 确认 `board.h` 的 HALF_TRACK / HALF_WHEELBASE |
| 手柄没反应 | 掉线 / DI-DO 反 | LED 常亮 = 掉线；对调 PA6/PA7 |
| 动舵机就复位 | 5V 塌陷 | 加 470μF 电容；`SERVO_SPEED_DPS` → 150 |
| 舵机抖 | 超行程 | 收 `SERVO_PWM_MIN/MAX_US` |
| 电池很快没电 | 舵机堵转 | 摸哪个舵机发烫；检查机构有没有卡死 |
| 车一冲就翻 | 重心太高 | 加底部配重；降 `SPEED_GAIN_FORWARD` |
| 上坡溜车 | 摩擦不够 | 放坡道防滑撑地块；起步助力加到 0.20 |

## 11. 两套预设（复制到 config.h 即可切换）

### 预设 A：地面干净、电量充足（进攻型）

```c
#define MOTOR_DEADZONE           0.15f
#define SPEED_GAIN_FORWARD       0.95f
#define SPEED_GAIN_STRAFE        0.90f
#define SPEED_GAIN_YAW           0.50f
#define CHASSIS_ACC_UP           4.0f
#define CHASSIS_ACC_DOWN         8.0f
#define MOTOR_KICK_DUTY          0.10f
```

### 预设 B：地面脏 / 电量低 / 场地滑（稳守型）

```c
#define MOTOR_DEADZONE           0.24f
#define SPEED_GAIN_FORWARD       0.70f
#define SPEED_GAIN_STRAFE        0.65f
#define SPEED_GAIN_YAW           0.35f
#define CHASSIS_ACC_UP           1.5f
#define CHASSIS_ACC_DOWN         6.0f
#define MOTOR_KICK_DUTY          0.20f
#define MOTOR_KICK_MS            180
```

> 建议在代码里把两套都留着（用 `#if` 或注释块），
> 中场 2 分钟整备时可以根据上一局的手感快速切换。
