① 整车总览

电流走向：电池正 → 继电器 COM →（吸合后）NO → 7.4V 主干 → 分给降压模块和电机驱动；降压出 5V 再分给舵机、继电器线圈、PS2 接收器、STM32。

图 ①：整车总览——从电池到继电器、降压、再到四个负载。

② 四个并线节点

节点颜色哪些线并进来
COM—电池正极，单独一根，不并
7.4V 主干红继电器 NO + 降压 IN+ + 电机驱动 VM

⚠ 两条安全红线
1. 降压模块 IN+ 反接直接烧，接 7.4V 前务必看准正负。
2. 每接完一坨先量通断，确认地和 7.4V 不短路再往下走。
施工顺序（防乱防烧）
  1. 先接所有地（黑，全并一起）
  2. 再接 7.4V 主干（红）
  3. 再接 5V 主干（橙）
  4. 最后接信号线（蓝）
  5. 电池放最后一步才接
