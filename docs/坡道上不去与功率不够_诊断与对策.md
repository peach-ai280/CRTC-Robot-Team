## 零、一句话结论

**这不是"调调参数"能解决的事，是硬件选型本身不够——官方那套 TT 马达 + 麦轮的组合，在 26.6° 的坡面上只有约三分之一的余量，整车一超过 0.6kg 就上不去。**

而且**加大功率的方向不是加电压**（TT 马达额定只有 3~6V，我们已经在用 7.4V，已经超压 40%），
正确方向是**加扭矩（换减速比）+ 减少损耗（电池、线、接触电阻）**。

## 一、先把数字摆出来（这些是手册写死的，不是感觉）

### 1. 坡道到底多陡

手册第 16 页原文：

> 坡道为占据 1×2 单位区块，连接地面与高台的地形区。坡道的坡高为 **300mm**，**坡比为 0.5**。

- 1×2 单位区块 = **300mm × 600mm**
- 坡比 0.5 = 高 300 ÷ 水平 600
- **角度 = arctan(0.5) = 26.57°**（约 26.6°）

台阶坡道（e1、d8）：坡高 **150mm**、坡比同为 0.5 → **角度一样是 26.6°**，只是坡面短一半（水平 300mm）。

> ⚠ **"角度有点大"是正常的，手册就是这么定的。** 但值得量一下——现场坡道可能是临时搭的。
> 量法：量坡道从底到顶的**水平距离**。300mm 高对应 600mm 水平。如果实测水平只有 400mm，那现场搭成了 36.9°，属于搭错，可以反馈组委会。

### 2. 我们的电机是什么货色

官方物资表第 5 项：**TT 马达 单轴 1:48**，单价 ¥2.83。

公开数据（多个来源一致）：

| 项目 | 数值 |
|---|---|
| **额定电压** | **3 ~ 6V**（不是 7.4V！） |
| 空载转速 | 200~250 rpm @6V |
| **堵转扭矩** | **0.8 kg·cm @6V** |
| **堵转电流** | **1.5A @6V**（8.4V 时约 2.1A） |
| 齿轮箱 | **塑料齿轮** |
| 重量 | 30.6g |

关键：**它是 3~6V 的马达。**
手册规定"单一供电、额定 ≤7.4V"——我们上 2S 锂电（标称 7.4V / 满电 8.4V），**等于让一个 6V 的马达常年跑在 8.4V**。
有刷电机超压不会立刻烧，但**电流和发热按比例上升，塑料齿轮箱的寿命直接砍半**。这就是"马达承不住"的第一个来源。

### 3. 驱动是什么货色

官方物资表第 9 项：**DRV8833 红板**，4 个（两台车 → **一台车 2 个 = 4 个通道 = 正好一个电机一个通道**）。

| 项目 | 数值 |
|---|---|
| 持续电流 | 1.2A / 通道 |
| 峰值电流 | 2A / 通道 |
| 内部压降 | 约 0.6~1.2V |

**一台车 4 个电机，每个电机堵转就要 2.1A，而 DRV8833 单通道峰值只有 2A。**
→ 一上坡、电流一冲，驱动模块就进限流/过热保护，表现就是**"一冲一冲"、"软绵绵"、"越爬越没劲"**。

### 4. 车重决定一切

上坡需要的**每轮扭矩**，可以套一个很简单的公式：

```
每轮需要扭矩 (kg·cm) ≈ 0.34 × 车重 (kg)
```

| 车重 | 每轮需要 | 4 轮合计需要 | TT 1:48 能持续给 | 结论 |
|---|---|---|---|---|
| 0.5 kg | 0.17 | 0.68 | 4 × 0.28 = 1.12 | ✅ 能上 |
| 0.6 kg | 0.20 | 0.82 | 1.12 | ✅ 勉强能上 |
| 0.8 kg | 0.27 | 1.09 | 1.12 | ⚠️ 贴边，一打滑就上不去 |
| **1.09 kg（我们整车的设计重量）** | **0.37** | **1.46** | 1.12 | ❌ **差 30%，上不去** |
| 1.5 kg | 0.51 | 2.04 | 1.12 | ❌ 差 45% |

（TT 1:48 的"持续可用扭矩"按堵转的 1/4 取，即 0.8 ÷ 4 = 0.2 kg·cm @6V，8.4V 时约 0.28 kg·cm。这是工程上的常规取值，留够发热和寿命的余量。）

**结论：整车一旦超过 0.6kg，1:48 的 TT 马达就爬不动 26.6° 的坡。**
我们的车设计重量 1.09kg——**超了将近一倍**。这不是调参数能救的。

## 二、为什么"麦轮"让这件事雪上加霜

麦轮的爬坡能力差，是行业公认的结构性缺陷（连专利文献都在专门研究怎么给麦轮加爬坡防滑装置）。原因：

1. **接触是点接触 / 线接触**。每个轮子是靠一圈 45° 斜装的小辊子接地的，接地面积远小于普通轮胎，压强高、抓地力低。
2. **没有纯纵向牵引力**。麦轮的正向力会被斜辊子分解，一部分变成辊子自转白转掉。业界共识是"无法提供纯纵向牵引力，因此爬坡和越障能力较弱"。
3. **接触点小 → 一颠就悬空**。坡面上只要有一个辊子过了坡道棱边，那个轮子就瞬间失去附着。
4. **地胶表面 + 麦轮橡胶辊子，摩擦系数大概就是 0.5~0.7。**

**第 4 点最要命：**

```
要能上 26.6° 的坡，摩擦系数必须 ≥ tan(26.6°) = 0.50
麦轮在 PVC 地胶上的实际摩擦系数 ≈ 0.5 ~ 0.7
```

→ **余量几乎为零。** 地胶上有一点灰、一点水汽、辊子上有一点磨光，摩擦系数掉到 0.5 以下，**轮子就纯打滑，扭矩再大也没用**。

普通橡胶轮在地胶上的摩擦系数约 0.8~1.0，**余量 60% 以上**。

## 三、先花 3 分钟判断：到底卡在哪一环

**别急着买东西。先分清是"打滑"还是"没劲"——这两个的解法完全相反。**

| 你看到的现象 | 判断 | 病根 | 看第五节哪一档 |
|---|---|---|---|
| 轮子**转得飞快**、嗡嗡响、车几乎不往前走 | **打滑** | 摩擦不够（麦轮 / 地胶 / 车太轻压不住） | 第 3 档 A |
| 轮子**转得很慢甚至不转**、电机或驱动板**发烫** | **没劲** | 扭矩不够 / 过流保护 | 第 3 档 B、C |
| **一冲一冲**、走两步停一下 | **过流保护跳了** | DRV8833 单通道顶不住 | 第 2 档 D |
| 某个轮子**完全不转**或**咔咔响** | **齿轮扫了 / 线断了** | 塑料齿轮崩齿 | 第 3 档 D |
| 爬一半**车头翘起来**、后轮空转 | **重心太靠后** | 配重问题 | 第 1 档 C |
| 平地就好好的，**一上坡就瘫** | **电池撑不住** | 内阻大、瞬时掉压 | 第 2 档 A |

**再补两个 0 成本的量法：**

- **量电池**：万用表搭电池正负极。满电应是 **8.4V**。挂上坡时如果掉到 **6.5V 以下**，就是电池内阻太大 → 见第 2 档 A。
- **量坡度**：手机装个"水平仪"/"量角器"App，贴在坡面上读角度。26.6° 是规范值。实测超过 30° 就找组委会问。

## 四、★ 还有一个免费的大检查：麦轮装反了没

**这一条能单独解释"没劲"和"乱跑"。**

麦轮分 **A 型（辊子左旋）** 和 **B 型（辊子右旋）**。标准 X 型四轮布局要求：

```
        车头
  左前(B)      右前(A)
  左后(A)      右后(B)
        车尾
```

**检查方法（不用拆）：**
把车架空，四个轮子往前转，从上往下看，**左侧两个轮的辊子接触地面那一点，应该同时朝车头方向；右侧两个轮同时朝车尾方向**（或整体镜像反过来）。四个轮连起来在地面画出来是一个 "X"。

**如果装错了**：四个轮子互相打对台，电机在使劲但力全互相抵消——平地就慢，一上坡直接瘫。而且耗电、发热都翻倍。

> 我们配件是"麦轮一套 4 个"，**开箱时左右是配好的**，装的时候别把顺序打乱。左前左后不是同一型。

## 五、怎么办 —— 按代价从低到高，五档

### 第 1 档：免费，今天就做

**A. 助跑冲坡。**
坡道是 1×2 区块，底端外面还有平地。**从 600mm 开外全速冲上去**，用动能顶着过最陡的一段。这是最有效的一招，因为 5 分钟内比赛，你只要上一次坡就够了。

**B. 正对上坡，别斜着上。**
麦轮斜着上坡会沿辊子方向侧滑，等于自己给自己打滑。**车头正对坡道中线，垂直上。**

**C. 减重 + 重心压低靠中。**
- 试底盘阶段就**别装储仓、机械臂、甲板**——那些加起来 500g 以上。
- 电池**尽量放低、放在车体中间**。上坡时重心后移，重心太靠后会抬起前轮，只剩两个轮子驱动。
- 装完第一件事：**上秤**。

**D. 比赛用满电的电池。**
8.4V 满电比 6.8V 亏电，扭矩高 **23%**。这不是小数。**带两块备用电池，每局换一块满电的。**

**E. 先从"矮坡"练。**
e1 / d8 的坡道是 **150mm 高、坡面水平 300mm**。角度一样是 26.6°，但**爬升高度只有一半，需要的能量只有一半**。先用这两条练，成功率高得多。

### 第 2 档：几十块钱的电气改造（性价比最高）

**A. ★ 换高倍率动力 18650。**
这大概率就是"整体功率不够"的主因。
- 4 个电机堵转一瞬间要 **6~8A**。普通 18650（容量型，2C 放电）内阻大，电流一冲电压就塌。
- 换**持续放电 10A 以上**的动力电芯：索尼 VTC6 / 三星 25R / 30Q，或国产标注 10C 以上的。约 **¥15~25/节 × 2 节**。
- ⚠ 仍然是 2 节、仍然是 7.4V，**不违规**。

**B. ★ 电机供电走粗线，绕开面包板。**
面包板每个簧片接触电阻 20~100mΩ，杜邦线 28AWG 也细。**2A 电流下，光这些接触点就能吃掉 0.5V 以上**。
- **电机回路（电池 → DRV8833 → 电机）单独用 20~22AWG 硅胶软线，直接对接，不走面包板。**
- 面包板只留给信号线（PS2、舵机 PWM、使能）。

**C. 每个 DRV8833 模块旁边并一个电解电容。**
470µF ~ 1000µF，耐压 16V 以上。**紧贴模块的 VM 和 GND 焊**。
作用：堵转的瞬间电流从电容里出，不从电池里出，避免电池被瞬时拉垮。
⚠ 电解电容**有正负极**，长脚是正，别接反（接反会炸）。

**D. 确认"一个电机一个通道"。**
官方一台车给 2 个 DRV8833 = 4 个通道 = 4 个电机**正好一拖一**。别为了省事拿一个通道带两个电机，那一定没劲。

**E. 检查 DRV8833 的 nSLEEP 引脚。**
有些模块的 nSLEEP 悬空时输出很弱或不出力。**接 VCC**（模块上一般已经拉了，但确认一下）。

### 第 3 档：机械改动（最有效，要花点钱动手）

**A. 给麦轮辊子加防滑（¥5~20，成本最低的机械改动）**
- 每个辊子上套一圈 **O 型橡胶圈**，或缠几层**热缩管**，或把硅胶条塞进辊子之间。
- 目的：把辊子与地胶的摩擦系数从 0.5 拉到 0.8 以上。
- 代价：横移会稍微变钝一点点，但换来的是能爬坡。

**B. ★★ 换成 60mm 橡胶轮（最有效，且完全合规）**
- **合规性**：手册附录注 2 原文——"**对于新生组而言，CRTC 官方物资表作为官方推荐的物资清单**，参赛队员可考虑购买其他不在 CRTC 官方物资表内的物资参加比赛，但购买的物资仍需符合赛事规则。"
  **注 3 的"唯一指定物资清单"只约束非新生组。我们是新生队，可以买表外物资。**
- 规则对"底盘运动"的判定只写"能用 PS2 手柄控制底盘的**水平运动**"，**没有强制麦轮、没有强制全向、没有强制爬坡能力**。
- **效果**：摩擦系数从 0.5 → 0.9，等于牵引力接近翻倍。26.6° 立刻从"上不去"变成"轻松上"。
- **代价**：失去横移（全向）。**但横移对拿分不是必须的**——贴边、对位用差速转弯都能做。
- 买法：搜"**60mm 橡胶轮 TT 马达 通用 D 轴**"，¥10~20 / 4 个。
- ⚠ 必须买 **D 轴 5.5mm 孔**（TT 马达输出轴就是 D 轴）。

**C. ★★ 换 1:120 减速比的 TT 马达（真正解决"扭矩不够"）**
- 同一款马达，齿轮比从 1:48 换成 **1:120**：
  - **扭矩 × 2.5** → 持续可用约 0.5 kg·cm @6V、0.7 kg·cm @8.4V
  - 4 轮合计 2.8 kg·cm，**需求才 1.46** → **余量接近 2 倍，稳上**
  - 速度 ÷ 2.5 → 从约 0.88 m/s 降到约 **0.35 m/s**
- **代价：慢。** 全场 2.4m 跑一趟要 7 秒。5 分钟的比赛还够用，但**抢块会比对手慢**。
- 买法：搜"**TT 马达 1:120 单轴**"，¥3~4/个 × 8 个 = **约 ¥30**。
- ⚠ 一定买**单轴**版（双轴装不进原来的联轴器）。
- ⚠ 换完**必须重新标定速度宏**，见第六节。

**D. 换 1:90 金属齿轮 TT 马达**
- 扭矩 ×1.9、**金属齿轮不扫齿**，速度降到约 0.45 m/s。
- 是"速度"和"爬坡"之间的折中点，但**扭矩余量只有 30%，还是贴边**。不如直接上 1:120。
- ¥6~8/个。

**E. 换 N20 / 370 减速电机（激进方案）**
- N20 金属齿轮 1:150 左右，扭矩 1~3 kg·cm，那才是真的"有劲"。
- **但**：安装座要 3D 打印、联轴器要重做、底板孔位要改 → **要队友配合，工作量大**。
- 建议**先不动**，等第 3 档 B+C 试完再说。

### 第 4 档：如果连 B+C 都不想动

**A. 用"麦轮 + 橡胶爬坡套"两套轮子。**
平时用麦轮（要横移），要上坡前 10 秒把橡胶轮换上（TT 马达拆装轮子只要拧一个螺丝）。
**这是最省事的组合拳**：¥15 买一套橡胶轮当备用，比赛看路线决定用哪套。

**B. 只走地形简单的那半场。** 见第七节。

## 六、换完减速比后，代码要改哪些

换 1:120 后，**轮子转得慢了 2.5 倍**，但麦轮逆解的几何参数（WHEELBASE / TRACK / 轮半径）**不用改**——那是几何，不是转速。

要改的是**速度标定**这三个宏（`firmware/Core/Inc/config.h`）：

```c
#define SPEED_GAIN_FORWARD       0.85f   /* 平地巡航，可以保持 */
#define SPEED_GAIN_STRAFE        0.85f   /* 必须和 FORWARD 相等，否则斜着走会偏 */
#define CHASSIS_ACC_UP           3.0f    /* 起步斜坡 */
```

**做法（顺序别乱）：**

1. **先跑平地标定**：编 `motion` 目标烧进去，手柄推到底直走 1m，量时间，算出实际速度。
   - 1:48 理论 0.88 m/s → 1:120 应该在 **0.35 m/s** 左右。偏离太多说明有轮子装错或打滑。
2. **`SPEED_GAIN_FORWARD` 和 `SPEED_GAIN_STRAFE` 必须始终相等**。
   不等的话，斜向走会偏——1:48 的情况下，0.85 对 0.80 就会偏 1.74°。这是我们已经踩过的坑。
3. **`CHASSIS_ACC_UP` 从 3.0 提到 5.0~6.0**：1:120 起步更"沉"，斜坡太缓会显得肉。
4. **起步 kick 可以调大一点**：`MOTOR_KICK_DUTY` 从 0.12 提到 0.18，帮它从静止捏过静摩擦。
5. 改完按自检流程跑一遍：`python tools\build.py all` → `python tools\check_symbols.py`。

**（可选，进阶）加一个"爬坡档"：**
在手柄上留一个按键，按下去时把 `SPEED_GAIN_FORWARD` 临时提到 1.0、`CHASSIS_ACC_UP` 提到 8.0。
平地用 0.6 保护电机，上坡时一键给满。这样既保护马达又能爬坡。

## 七、★ 战术绕行：其实不一定非得上坡

**这是 0 成本、且最应该先算清楚的一件事。**

### 场地上的道具分布（手册第 17–18 页）

**白色能量单元（1 分，共 18 个）：**

| 位置 | 要不要上地形 |
|---|---|
| a8、h1 地块中心 | ❌ **地面，直接拿** |
| c4、f5 地块中心 | ❌ **桥下地面**（桥梁净高 130mm，下方有通行空间，车能钻进去） |
| d6、e3 台阶内侧四分之一处各 1 个 | ⚠️ 要上 150mm 台阶 |
| e8、d1 台阶几何中心 | ⚠️ 要上 150mm 台阶 |
| e8'、d1' 附属高台矮墙中心 | ⚠️ 要上 20mm 附属高台（好上） |
| 地图中心轴距中心 40mm 处四个（矮墙限位） | ❌ 在中央高地上，要上 300mm |

**黄色能量核心（4 分，共 5 个）：**

| 位置 | 要不要上地形 |
|---|---|
| e3、d6 的物资架（质心距地 250mm） | ⚠️ 要上 150mm 台阶后才够得着 |
| **d1、e8 台阶下的洞穴（70×70×50，向外开口）** | ✅ **地面就能探！** 我们已经设计了 `17_cave_probe` 洞穴探杆 |
| 中央高地焦点平台中心 | ⚠️ 要过桥或上坡到 300mm 高地 |

### 所以不上坡也能打

- **地面白块 a8 / h1 / c4 / f5 = 4 分**（半自动 ×1.5 = 6 分）
- **洞穴黄块 d1 / e8 = 8 分**（半自动 ×1.25 = 10 分）
- 合计够一个体面的成绩，**而且这三个位置我们都有对应机构（探杆）**。

### 上坡的最优路线

一定要上坡的话，**先攻 e1 / d8 的 150mm 矮坡**（爬升只有一半），上了台阶就能勾 e3 / d6 的物资架黄块。
**300mm 的中央高地和高台，是最后才考虑的。**

## 十、今天/明天就能做的 5 件事

1. **量坡度**：手机水平仪贴在坡面上读角度。26.6° 是规范值。
2. **判类型**：上坡时轮子**转得快但车不动** → 打滑；**转得慢/发烫** → 没劲。拍照/录像记下来。
3. **查麦轮**：架空车，四轮往前转，看是不是"左两个朝前、右两个朝后"的 X 型。装错就重装。
4. **量电池**：万用表量满电电压（应 8.4V），再量爬坡瞬间（别低于 6.5V）。
5. **称车重**：整车多少克？**超过 600g 就别指望 1:48 上 300mm 坡了。**

把这 5 个数据记下来，就能确定买 4 还是买 5、要不要买 1。
