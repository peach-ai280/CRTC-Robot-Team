# 进阶功能方案（3 项 · 最高 +9 分）

## 规则约束（先读）

手册 4.1.2 对进阶功能的四条要求：

1. **不等同或等价于任何一项基础功能指标**
2. **不等同或等价于任何一项"因为没有统一测试条件而没加进基础指标"的较基础功能**
   （手册举例：机器人能够上坡 —— 这条要特别小心）
3. 具有一定的创新性和独特性
4. **可以明确由视频材料判断该指标是否被实际完成**

每项按【创新度】【实现难度】【完成度】三项打分，各满分 3 分、最小 0.5 分，
取均值。最多提交 **3 项**，所以最高 **+9 分**。

> 前提：**必须完成全部基础功能指标**才能拿进阶分。
> 没完成基础功能的队，不能靠进阶功能加分。

## 进阶 1：斜槽重力自锁多块储运仓

### 为什么不算"等价于基础功能"

基础功能只考核"携带多项"这个**结果**；本项考核的是**任意姿态下的自锁可靠性**，
并且给出可量化的测试方法与数据。视频能明确判断。

### 机构

- 3 格斜槽，底板**前低后高 5°**
- 每格顶部一片单向挡板（`15_bin_flap.stl` ×3），M2.5 铰接，只能向内翻
- 挡板背面贴 1.5g 配重（螺母）防止颠簸时弹开

### 可量化的演示（视频拍这三段）

| 测试 | 方法 | 判定 |
|---|---|---|
| 急停 | 全速前进 → 松摇杆刹车，重复 3 次 | 方块不滚出 |
| 横移 + 自转 | 满速横移同时自转 5 秒 | 方块不甩出 |
| 跌落 | 180mm 自由跌落 | 方块不掉出 |

> 第三段特别值：它同时是"结构稳定性"基础指标的演示，
> 一次拍摄能证明两件事。

### 不需要补买硬件

用到的都是已有的 PLA 打印件 + M2.5 螺杆 + 双面胶 + 1 个小螺母。

## 进阶 2：机械对中 + 一键半自动收集宏

### 为什么不算"等价于基础功能"

基础功能只要求"机器人能让方块变成携带状态"；
本项实现的是**无需操作手精细操作的完整动作序列**，
并且有三重安全设计（硬超时 / 失败自动收机构 / 摇杆随时接管）。
这是"半自动"认定的直接依据，对应 **×1.5 的得分倍率**。

### 硬件与成本

| 物品 | 数量 | 单价 | 小计 |
|---|---|---|---|
| 微动开关 KW11-3Z（带摆杆） | 4 只（每车 2） | ¥0.5 | ¥2 |
| 拉簧（回位用）或 橡皮筋 | 4 | — | ¥0 |
| 杜邦线 / 热缩管 | 若干 | — | ¥2 |
| **合计** | | | **≈ ¥4** |

接线：开关一端接 GND，另一端接 PB10（左） / PB11（右），
CubeMX 里设成 **GPIO_Input + Pull-up**。按下 = 低电平。

### 判定逻辑（已实现于 `sensor.c`）

```
左右两个开关都被压过 且 两次压下时刻差 < 400ms  =>  判定"已对中"
```

### 代码入口

- `firmware/Core/Src/sensor.c` — 去抖 + 对中判定
- `firmware/Core/Src/auto_task.c` — `MACRO_GROUND` 状态机
- 触发键：PS2 的 **○** 键

### 调试流程（新手可上手，约 30 分钟）

1. 架空，用手按压左右摆杆 → 串口 `limit L1 R1` 应变化
2. 只按左边 → 不应判定对中（只看串口不动作即可）
3. 左右都按（间隔 < 400ms）→ 触发宏
4. 落地：把方块放在正前方 30cm，按 ○ 键
5. 调 `AUTO_APPROACH_SPEED`（从 0.25 起试）和 `AUTO_APPROACH_TIMEOUT`

**最常见的失败**：只压到一个开关。
原因通常是**车斜着冲过去**，方块撞在喇叭口一侧。
解决办法是把靠拢速度降低、并且在操作上要求"车头正对方块再按宏"。

## 进阶 3：坡道防滑可收放摩擦支撑块

### 为什么不算"机器人能够上坡"

手册 4.1.2 第 2 条明确把"上坡"排除在进阶功能之外。
本项考核的不是"能不能上"，而是**打滑抑制的机构与控制策略**：
在坡度 0.5（≈26.6°）的坡道上，麦轮的塑料辊子会打滑，
我们用一个可收放的摩擦支撑块提高可用摩擦力。

### 物理原理

最大静摩擦 = μ · N。麦轮辊子是塑料、接触面积小，μ 很低。
支撑块用**橡胶**（自行车内胎剪的，μ 高得多）压地，
增加总的可用摩擦力，同时不改变麦轮的全向运动能力（平地上收起）。

⚠️ 关键：支撑块只能**轻触**地面提供额外摩擦，
不能把车顶起来（顶起来会让驱动轮卸荷，反而更滑）。

### 硬件与成本

| 物品 | 数量 | 单价 | 小计 |
|---|---|---|---|
| SG90 舵机（第 4 个，物资表已含） | 1 | — | ¥0 |
| 自行车内胎 / 橡胶垫 | 1 块 | ¥0（废物利用） | ¥0 |
| M3 螺杆 + 螺母 | 2 套 | — | ¥1 |
| `22_ramp_anchor.stl` 打印件 | 1 | — | ¥1 |
| **合计** | | | **≈ ¥2** |

### 代码入口

- 3D 件：`mechanical/stl/22_ramp_anchor.stl`
- 舵机：`SERVO_EXTRA`（PA3 / TIM2_CH4），角度 `SERVO_EXTRA_IN = 0` / `OUT = 180`
- 触发：目前挂在 `POSE_RACK_HOOK` / `POSE_CAVE_PROBE` 序列里；
  如果要独立控制，在 `app.c` 的 `handle_keys()` 里加一行：

```c
if (PS2_Clicked(PSB_R2)) {
    static uint8_t anchor_down = 0;
    anchor_down = !anchor_down;
    Servo_SetAngle(SERVO_EXTRA, anchor_down ? SERVO_EXTRA_OUT : SERVO_EXTRA_IN);
    LOG("[ANCHOR] %s\r\n", anchor_down ? "down" : "up");
}
```

⚠️ 注意：`SERVO_EXTRA` 同时被挑杆/探杆占用。
一台车一次只能装一种机构，**赛前二选一**。
如果两样都想装，需要再加一个舵机（补买 SG90 ¥5.9）。

### 调试流程

1. 先确认支撑块收起时离地 ≥ 10mm（平地行驶不蹭地）
2. 放下时橡胶垫刚好接触地面 —— **用手转轮子，应该还能转**，只是变沉
3. 上坡测试：从坡底起步，观察是否打滑
4. 如果还是打滑：检查橡胶垫是不是太硬；换成更软的（内胎比鞋底好）

## 关于"半自动"的认定，我们想说清楚

手册对半自动/全自动的定义（3.3.1）：

> 全自动机器人：在比赛过程中**无需配备操作手**，且经组委会审查确定为自动运行的机器人。
> 仅满足一部分前述特性的机器人统一称为半自动机器人。

我们的实现是：

- 操作手**必须一直在场**，负责"去哪、拿什么"的决策
- 按一个键触发一个**有时间上限、可被打断**的动作序列
- 车**不自主决策**、不自主搜索、不自主规划路径

所以它是"**仅满足一部分特性**" → 半自动。
我们**不申称全自动**，也不赌组委会的全自动认定。
得分按 ×1.5（能量单元）/ ×1.25（能量核心）计算。

> 中期考核答辩时，如果裁判问"你们这算不算全自动"，
> 标准回答：**"不算。决策权一直在操作手手里，我们只把重复的精细动作做成了宏。"**
