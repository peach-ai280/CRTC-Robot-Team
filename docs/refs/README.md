这个目录里放的是组委会和战队发下来的原始文件，不是我们写的。原样存档，没改过任何一页。

放这里的目的是让下一个做这台车的人能顺着同一份材料往下走，不用再去群里翻记录。**先看我们的 [复现指南](../复现指南.md)，再回过头查这里的原始文件**——手册和培训 PPT 讲的是通则，我们踩的坑是具体的。

## 怎么看这几份材料

**参赛手册**是唯一有约束力的文件，其他都是参考。里面有三处最容易看漏：

- 尺寸是分状态量的。初始状态（收起来）和变形状态（展开后）各有一条红线，不是同一个数。
- 得分只算「对局结束那一刻还在车上」的方块。中途搬到了、结束前掉了，不算。
- 报销有上限，而且**没通过中期考核的队伍不予报销**。钱和考核是绑在一起的。

注意手册会更新。我们手上这份是 V1.7，组委会说以届时发布的最高版本号为准，所以赛前一周要再去群里确认一次有没有新版。

**电控培训那份**，讲得最有用的是第 17 页和第 18 页：怎么分治排障，以及怎么用 AI。第 17 页那套「先让灯和串口说话，再谈逻辑」我们是照着做的，后面调 PS2 的时候就靠这个把问题缩到了两根线上。第 18 页说 AI 会非常自信地编造引脚号——这个我们也吃过，见 [复现指南 · 十一、踩过的坑](../复现指南.md#十一踩过的坑) 里「引脚表不是查出来的，是照着板子拍的」那条。

**机械培训那份**的价值在第 21 页那张公差速查卡：M3 通孔 Ø3.2–3.4、M3 自攻底孔 Ø2.5–2.7。但它自己写了「起手值，不是标准值」，得用自测件量出本机偏差。打印件有收缩，直接照表开孔往往偏小；我们最后干脆把和外购件配合的地方都做成槽，用 M3 大垫片压，比赌一个孔的直径稳。

**SG90 那个模型**我们没用上——车一最后用的是 MG995 加小 SG90，机构是照着实物量的。模型的用处是给机械组画图时定位用。
