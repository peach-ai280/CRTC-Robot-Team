# 舵机、机械臂与抓取机构

## 功能描述

用 3 个舵机（MG995 ×1 + SG90 ×2）完成"取地面方块 / 取台阶方块 /
挑物资架黄块 / 勾洞窟黄块"四类动作，并且满足基础功能考核里
**"舵机运动（多项）：同一台机器人至少三个舵机转动，
且其可动机构能在任意非初始状态下保持相对静止"** 这一条。

代码：`firmware/Core/Src/servo.c`（PWM + 缓动）、`arm.c`（动作序列器）。

### 2026-09-28 · 舵机 PWM：50Hz，比较寄存器直接填微秒

TIM2 配置：PSC = 71 → 1MHz 计数；ARR = 19999 → 50Hz（20ms）。
这样**比较寄存器的值就是脉宽的微秒数**（填 1500 = 1.5ms），调试时非常直观。

行程标定：

| 舵机 | 0° 脉宽 | 180° 脉宽 | 备注 |
|---|---|---|---|
| SG90 | 500 μs | 2500 μs | 实际可用行程比这个窄 |
| MG995 | 500 μs | 2500 μs | 同上 |

**"吱吱"抖 = 超行程**。我们第一次给 SG90 下 0° 命令时它一直在抖，
把 `SERVO_PWM_MIN_US` 从 500 收到 560 就好了。每次收 30μs，
收到不抖为止。

### 2026-09-28 · 舵机限速：为什么要给舵机做缓动

`SERVO_SPEED_DPS = 240`（度/秒），`Servo_Update()` 每 10ms 插值一次。

两个原因：

1. **电流**：舵机瞬间跳到目标角度会产生最大启动电流，是 5V 塌陷的主要来源
2. **机械**：夹爪突然夹紧会把方块弹飞；大臂突然落下会砸到自己的铲子

代价是动作变慢，但我们判断值得（理由见 `04` 板块的 5V 塌陷分析）。

### 2026-09-29 · 舵盘转接板：别把臂直接拧在塑料舵盘上

第一版我们把大臂用自攻螺丝直接拧在 MG995 自带的塑料舵盘上。
夹紧之后一用力，螺丝就在塑料里滑牙了。

**解决**：打印了一块 `11_servo_horn_plate`（32×32×3mm），
先用 M2 自攻把转接板固定到塑料舵盘上（4 点固定，受力分散），
再把臂锁到转接板上（金属对金属，或者至少是 PLA 对 PLA 的平面压紧）。

这块 3g 的板子解决了整个机构最薄弱的一环。

### 2026-09-30 · 动作序列器：一次只动一个舵机

原实现：

```c
// v1（错）
Servo_SetAngle(SERVO_ARM,  ARM_GROUND);
Servo_SetAngle(SERVO_GRIP, GRIP_HOLD);
Servo_SetAngle(SERVO_SCOOP,SCOOP_DOWN);   // 三个一起动 -> 5V 塌陷 -> 复位
```

改成串行序列器：

```c
typedef struct { ServoId_t servo; float angle; uint16_t wait_ms; } Step_t;

static const Step_t seq_pick_ground[] = {
    {SERVO_SCOOP, SERVO_SCOOP_DOWN,      150},
    {SERVO_ARM,   SERVO_ARM_GROUND,      400},
    {SERVO_GRIP,  SERVO_GRIP_HOLD_CUBE,  220},
    {SERVO_ARM,   SERVO_ARM_LIFT,        400},
    {SERVO_SCOOP, SERVO_SCOOP_UP,        350},
    {SERVO_GRIP,  SERVO_GRIP_OPEN,       150},
    {SERVO_ARM,   SERVO_ARM_STOW,        250},
};
```

`Arm_Update()` 的逻辑：当前舵机还在动 → 等；到位了 → 再等 `wait_ms`；然后下一步。

一个完整地面取块动作约 **1.2 秒**。

### 2026-10-01 · "舵机运动（多项）"考核点怎么过

考核原文：

> 同一台机器人能完成至少三个舵机的转动并确保其可动机构能够
> 在**任意非初始状态下保持相对静止**

拆解成两个判定：

1. **三个舵机都要转**：我们的序列器里 `POSE_STOW` 一次就动了 4 个（含备用），满足
2. **任意非初始状态保持相对静止**：SG90 / MG995 都是**自带减速箱的模拟舵机**，
   断电/保持时齿轮箱自锁力矩足够，用手掰不动

⚠️ **注意**：不要把舵机设成"弹簧回中"模式，也不要用那种通电才保持、
断电就松的数字舵机模式。我们用的是默认模拟舵机 + 持续发 PWM，
`Servo_Update()` 会一直维持脉宽，所以任意角度都能保持。

**演示方式**（写进视频脚本了）：三个舵机停在中间角度 → 用手掰 → 掰不动 → 松手 → 角度不变。

### 2026-10-03 · 夹爪：1mm 硅胶垫是成败关键

**现象**：夹爪能夹住方块，但车一走（尤其是加减速）方块就掉了。

**原因**：PLA 表面很光滑，和方块（也是 3D 打印的 PLA）之间的摩擦系数很低。

**解决**：在夹爪内侧贴 **1mm 厚的 EVA 泡棉 / 硅胶垫**（用双面胶贴）。
摩擦系数大概翻倍，而且软垫能补偿 2mm 的尺寸误差 —— 方块不是每次都停在正中间。

夹爪角度：

| 状态 | 角度 | 说明 |
|---|---|---|
| 张开 | 30° | 让 46.4mm 喉口的方块能进来 |
| 夹白块（能量单元） | 86°（待标定） | 30mm 方块（V1.4） |
| 夹黄块（能量核心） | 74° | 黄块倒角略大，实测夹紧角要小一点 |
| 闭合到底 | 95° | 空夹时的极限（不要长时间停在这里，会堵转发热） |

### 物资架（★ 2026-10-04 重算：原来够不到，已补增高座）

**规则**：物资架是 φ14、长 150mm 的圆柱，与地面平行，固定在高台侧面，
黄块挂/放在上面，**方块质心距地 250mm**。车是站在地面去够它的。

**⚠ 2026-10-04 核算时发现的原设计缺陷**：

```
肩关节高度 = 板面 30 + 立柱 22 + 甲板 4 + 舵机轴高 20 ≈ 76mm
臂展       = 大臂 86 + 小臂到夹爪中心 50 = 136mm
最大可达   = 76 + 136 = 212mm  <  250mm    ❌ 够不到！
```

也就是说，按原来的装配，**物资架那个黄块是拿不到的**。

**已修**：新增 `25_arm_riser` 机械臂增高座（60mm 高，框型，扎带固定）：

```
肩关节高度 = 76 + 60 = 136mm
最大可达   = 136 + 136 = 272mm  ≥  250mm    ✅ 能夹到，余 22mm
```

**收起时超不超 210mm 红线？不超。** 收起姿态是大臂**平放**，
最高点 ≈ 肩高 136 + 大臂半宽 12 ≈ 148mm，离红线还有 62mm。
（只有"初始状态"才卡 210mm，比赛中变形是允许的。）

**两种取法，先用第一种**：

1. **直接夹**（推荐）：车开到架子前 → 大臂举到 `ARM_RACK` → 夹爪对准黄块 → 夹紧 → 收回。
   加了增高座之后这个动作在几何上是可行的。
2. **挑杆挑下来**（兜底）：`16_rack_hook` U 型叉口从黄块下方兜住，车后退把块带下来，
   掉地上再用铲收。适合夹爪对不准的时候。

> ⚠ **黄块到底是"穿在圆柱上"还是"搭在末端"，现场要第一眼看清楚**（见遗留问题）。
> 这直接决定用"夹"还是"挑"。**两种机构都打了，现场选。**

### 洞窟探杆方案（待实测）

d1 / e8 台阶下有 70×70×50mm 向外开口的洞窟，里面各 1 个黄块
（"外平面与洞口相切，径向居中"——也就是方块几乎就在洞口，不用伸很深）。

探杆 `17_cave_probe`：截面 12×12mm，前端钩深 12mm。

**动作**：大臂降到洞口高度 → 车缓慢前进让钩子插入 → 稍微上抬勾住 → 缓慢倒车（速度 ≤ 0.20）拖出来。

⚠ **两个已知的失败模式**（装完车实测时要重点看）：
1. 钩太浅，倒车时块滑掉 → 对策：钩深加到 20mm，倒车速度降到 0.20
2. 倒车加速度太大 → 对策：底盘已有加速度斜坡，把 `ACC_DOWN` 再调小一点

**成功率：【待实测】，不要预先写结论。**

### 2026-10-10 · ★★★ 机械臂整体推翻重做：改成「盒式臂座 + 平行四连杆 + 平行爪」

> 本节前半部分（09-29 的 `11_servo_horn_plate`、10-04 的 `25_arm_riser` 增高座、
> 以及"大臂 MG995 收起 25 / 地面取块 120 / 台阶 78 / 挑物资架 15"那张角度表）
> **全部属于旧的两自由度平面连杆方案，已作废**。
> 下面是照队内参考视频重做的方案。

**为什么推翻**：旧方案是"肩 + 肘两个俯仰自由度"，靠加高座 + 加长臂去够 250mm 的物资架，
结果是"够到了但姿态不受控、还要做逆解"。新方案改用**平行四连杆**：
主臂 A→B 与平行杆 A′→B′ 等长（105mm）且始终平行 → **肘座姿态恒定水平 → 爪指永远朝下**，
**不需要逆解、不需要第二个俯仰舵机**。旧件 `09_arm_upper` / `10_arm_fore` /
`11_servo_horn_plate` / `11b_claw_adapter` / `25_arm_riser` 全部弃用。

**新的三个舵机（都是臂上的）**：

| 编号 | 型号 | 装在哪 | 动作 |
|---|---|---|---|
| S1 | **MG995** | 臂座内腔（侧躺），驱动主动轴 A | 整条臂在竖直平面内上下摆，**φ = −50° ~ +90°** |
| S2 | **SG90** | 臂座内腔上部，轴朝上，驱动回转盘 | 整条臂绕竖直轴回转（工作 ±120°，收起 180°） |
| S3 | **SG90** | 趴在平行爪底板 `24h` 上 | 齿轮版平行爪开合（`24f` 齿轮 + `24g` 齿条滑块 + `24i` 爪指） |

**换算式（标定用）**：`舵机角 s = 90 + φ`。装好臂后让 S1 打到 `s = 90`，
把机械中位装成"水平朝前"即可。**这是全车唯一必须靠装配对一次的地方。**

**★ 角度表全部改成 φ 口径（旧的那张作废）**：

| 姿态 | 固件常量 | 舵机角 s | 摆角 φ | 用途 |
|---|---|---|---|---|
| 硬下限 | `SERVO_ARM_MIN` | 40 | −50° | 只用来"压到底让开铲"，不用它取块 |
| 焦点取块 | `SERVO_ARM_FOCUS` | 64 | −26° | 中央焦点黄块 |
| 收起 / 水平 | `SERVO_ARM_STOW` | 90 | 0° | 配合 `SERVO_YAW_STOW = 180` 平躺朝后 |
| 中央高台面 | `SERVO_ARM_PLATFORM` | 101 | +11° | 高台面白块（车先走桥上去） |
| 台阶面 | `SERVO_ARM_STEP` | 109 | +19° | 台阶面白块 |
| 举起 | `SERVO_ARM_LIFT` | 125 | +35° | 拖物资架黄块用 |
| 最高 | `SERVO_ARM_RACK` | 180 | +90° | 举到最高（只能夹物资架黄块**下半截**） |

**★ 取块分工整个变了**：

| 目标 | 结论 | 归谁管 |
|---|---|---|
| 地面白块 | ❌ 臂够不到（−50° 以下主臂就扫到收集铲） | **前铲** |
| 台阶面白块（150~180） | ✅ φ=+18.0°~+20.3° | 臂 |
| 中央高台面白块（相对车底板 135~165） | ✅ φ=+9.6°~+11.8° | 臂 |
| 焦点黄块（相对车底板 70~100） | ✅ φ=−26.9°~−24.5° | 臂 |
| 物资架黄块（235~265） | ⚠ **只能夹下半截**（φ=+90° 时重叠仅 17.5mm） | 臂，先用爪沿 φ14 圆柱往外拨再夹；**取不下就放弃** |
| 洞穴黄块 | ❌ 爪外宽 74 > 洞宽 70 | **洞窟探杆 `17_cave_probe`**（不变） |

**★ 动作序列铁律：抬平 → 回转 → 再摆臂。**
带着伸直的臂硬回转，爪会扫到储仓和车架，而回转 SG90 的扭矩账只有约 1.2 kg·cm，
扫一下就扫齿。所以 `arm.c` 里所有序列都强制先 `SERVO_ARM → 90` 再动 `SERVO_YAW`。

**★ 收起姿态 = 检录位 = 「yaw 180° 朝正后方 + φ 0° 水平平躺」**：
全车长 **282.5mm**（红线 290）、最高 **196.5mm**（红线 210）、爪最低 113.5mm。
⚠ 爪的落点是 `x = 106 − (18+105) = −17`，这直接决定了储仓必须前移
（见 `07_方块携带与储仓.md` 的 10-10 板块 与 `docs/批判与修正记录.md`）。

**★ 第 5 路舵机（臂回转）：TIM1_CH4 = PA11。**
TIM2 四路已满、TIM4 是电机、**TIM3 三组引脚全部撞车**（详见 `board.h` 注释）。
⚠ TIM1 是高级定时器，不置 `BDTR.MOE`(bit15) 所有通道被硬件关断；
⚠ **PA11/PA12 接在 micro-USB 座上，调车时不能插 micro-USB 供电**。

**★ 精度上限不变**：末端 **±5~10mm**（臂长 105mm，1° ≈ 1.8mm），夹爪余量约 16mm
→ 能抓但不稳。**不要把"精准抓取"报进阶功能。**

修正过程（为什么是现在这样）见 `docs/批判与修正记录.md`。**
