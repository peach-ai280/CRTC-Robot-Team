## 0. 安全前提（写在最前面，不是废话）

1. **任何时候焊接/改动线路，电池必须拔下来。** 不是关机，是物理断开。
2. **18650 严禁短路。** 正负极一旦被导线/焊锡/工具同时碰到，瞬间几十安培，电池会烫到无法手持并可能起火。处理裸线头时先包好一端再包另一端。
3. **第一次上电必须"架空"**：把车架起来（书本/盒子垫住底盘），四个轮子离地。这样即使程序让电机反转、占空比给满，车也不会窜出去撞人或撞墙。
4. **上电顺序**：先接电池 → 观察有没有冒烟/异味 → 摸一下驱动芯片温度（不烫手为正常） → 再放手操作。**一旦发现芯片迅速发烫，立刻拔电池。**
5. **不要在没断电的情况下插拔杜邦线。** 杜邦线插歪一位（比如 5V 插到 3.3V）就会烧掉 STM32。
6. 调试时旁边放一把斜口钳，随时能剪线断电。

## 1. 电源树 —— 先搞懂电从哪来到哪去

### 1.1 规则约束（手册 3.3.2 / 3.3.6）

| 约束 | 内容 | 对我们的影响 |

| 供电模块 | 每台机器人**仅允许 1 个**供电模块，额定电压 **≤ 7.4V** | 只能用 2 节 18650 **串联**（标称 7.4V，满电 8.4V），不能两串两并、不能额外加电池 |
| 供电模块定义 | **有且仅有一个输出接口** 的供电装置 | 电池盒出来的那对线只能是一路。所有分支必须在**电池之后**分，不能在电池盒内部做成两路输出 |
| 无线继电器 | 必须适配官方指定款，**10m 内可遥控切断底盘电源** | 检录必查。未通过中期考核的队不用买，通过后再买 |
| 成本 | 新生组不推荐超过 400 元；报销上限 400 元 | 官方物资表已 353.48 元，剩下的钱只够少量补买 |

### 1.2 电源树图

```
   18650×2 串联（7.4V 标称 / 8.4V 满电）
            │
            │  ← 电池盒自带的两根线（红 + / 黑 -）
            │     这"一对线"就是规则里说的"唯一输出接口"
            ▼
   ┌──────────────────┐
   │  无线继电器 接收器  │   IN+ / IN-  ← 直接接电池（见下方 ⚠）
   │  （DC 5-24V 款）   │   OUT+ / OUT- ← 被控输出，接整车
   └──────────────────┘
            │  OUT+ / OUT-
            ▼
        节点 P（7.4V 受控）—— 断电遥控器一按，这里就没电
            │
            ├──────────────► DRV8833 #1 的 VM   （电机动力）
            ├──────────────► DRV8833 #2 的 VM
            │
            └──────────────► Mini 降压模块 IN+
                                    │
                                    ▼  5V
                        ┌───────────┼───────────────┐
                        ▼           ▼               ▼
                   STM32 的 5V 脚   MG995 ×1     SG90 ×3
                   （板载 AMS1117    （红=5V）    （红=5V）
                    再转 3.3V）
                        │
                        ▼ 3.3V
                   PS2 接收器 VCC、DRV8833 的 VCC（逻辑）
```

### 1.3 ⚠ 两个新手必踩的坑

**坑 1：继电器线圈的取电位置**
继电器的 `IN+ / IN-` 必须接在**电池直出处**（继电器之前），`OUT+ / OUT-` 才接整车。
如果反过来（把继电器线圈也接在 OUT 后面），一按断电，继电器自己也没电了，就再也合不上 —— 车永久断电，当局直接废。

**坑 2：DRV8833 的逻辑电源 VCC**
DRV8833 芯片的 `VCC`（逻辑）规格是 **1.8 ~ 7V**，而 `VM`（电机动力）可以到 10.8V。
市面上几块钱的红色 DRV8833 模块，为了省事通常把 VCC 通过一颗 0Ω 电阻/一小段铜箔**直接接到 VM**。
我们电池满电 8.4V > 7V，长期运行有击穿风险。

> **必做改造（5 分钟）**：
> 用万用表蜂鸣档量模块上的 `VCC` 引脚和 `VM` 引脚，如果**是通的**，说明内部短接了。
> 找到两者之间的 0Ω 电阻（或直接用刀切断那一段铜箔），然后把 `VCC` 单独飞一根线到降压模块的 **5V** 输出。
> 改完再量一次：VCC 与 VM 之间应该是**不通**的。

### 2.3 电池电压检测分压

```
节点 P (7.4V) ── 20kΩ ──┬── 10kΩ ── GND
                        │
                        └── PB1 (ADC)
```
分压比 = (20k + 10k) / 10k = 3。满电 8.4V → PB1 上是 2.8V，低于 3.3V 安全。
`config.h` 里 `VBAT_ADC_DIV = 3.0` 对应这个比值。
**如果手头只有其他阻值，改 `VBAT_ADC_DIV = (R上 + R下) / R下`。**

### 2.4 PS2 接收器接线

| PS2 模块脚 | STM32 | 说明 |
|---|---|---|
| VCC | 3.3V | **官方套件里的 PS2 接收器多数是 3.3V 逻辑，接 5V 有风险。** 若你的模块标注 5V 则接 5V，但 SPI 上拉会偏强，一般也能用 |
| GND | GND | |
| DI / MOSI | PA7 | 有的模块标 "DI"，指"到手柄的数据"，对应 MCU 的 MOSI |
| DO / MISO | PA6 | 对应 MCU 的 MISO |
| CLK | PA5 | |
| CS / ATT | PB0 | |

> **判断 DI/DO 有没有接反的最快方法**：上电后串口打印 `PS2: no handshake`（或 mode 一直是 0），
> 把 PA6 / PA7 两根线对调再试。90% 的 PS2 调不通都是这两根线反了。

## 3. 焊接点位清单

> 物资表里 STM32 是"**Micro_焊接**"款 —— 到手是散件，排针要自己焊。
> 面包板只能用来做前期验证，**正式车必须用洞洞板（万能板）或自制 PCB**：
> 手册 3.3.3 明确写着"单一使用杜邦线易出现连线脱落"，而且结构强度检测是从 180mm 高处跌落。

### 3.1 必焊点位（按推荐顺序）

| # | 点位 | 焊接内容 | 难度 | 注意 |
|---|---|---|---|---|
| S1 | STM32 排针 | 2 × 20pin 排针焊到核心板两侧 | ★★☆ | 先焊对角两针固定，确认排针垂直再焊其余；烙铁 320℃，每针不超过 3 秒 |
| S2 | STLink 排针 | 4pin（SWDIO/SWCLK/GND/3V3） | ★☆☆ | 通常已焊好 |
| S3 | 电池盒引线 → 继电器 IN | 红→IN+，黑→IN− | ★★☆ | **焊前先把线头镀锡**；焊完套热缩管；正负极**分开套**，别用一根大套管 |
| S4 | 继电器 OUT → 主电源插头 | 建议用 XT30 或 2P 端子 | ★★☆ | 这是"供电模块唯一输出接口"，做成**一个**插头，不要分成两路 |
| S5 | 电机线 → DRV8833 输出 | 8 根（4 电机 × 2） | ★★☆ | TT 马达线细，剥线 3mm 即可，镀锡后焊 |
| S6 | 舵机接头 | 一般不用焊，插杜邦即可 | ★☆☆ | 但**必须用热熔胶把插头固定住**，否则跌落测试必掉 |
| S7 | 洞洞板转接 | STM32 + 2×DRV8833 + 降压 + 排针座 | ★★★ | 见 3.2 |

### 3.2 强烈建议做的一块"转接板"（洞洞板方案）

与其插 30 根杜邦线，不如花 2 小时焊一块 7×9cm 洞洞板：

```
洞洞板布局（俯视，从上到下）：

 [ 2×20 排母 ]   ← STM32 核心板插这里
 [ 2×5  排针 ]   ← 电机 PWM + DIR 引出（8 针 + GND + 5V）
 [ 4×3  排针 ]   ← 舵机 4 路（信号/5V/GND）
 [ 1×4  排针 ]   ← PS2（VCC/GND/DI/DO/CLK/CS）
 [ 1×2  排针 ]   ← 限位开关（信号/GND）
 [ 2P 电源端子 ] ← 7.4V 入
 [ 2P 电源端子 ] ← 5V 出（给舵机）
```

- STM32 用**排母**插上去（方便烧录后拔下来），其余全部用排针。
- 板上所有 GND 用一根粗铜线（或焊锡堆）连成一片。
- **5V 走线要粗**：4 个舵机峰值可能 1.5A，洞洞板的细铜箔不够，直接在板背面焊两根 0.5mm² 的导线做 5V 和 GND 主干。

### 3.3 焊接工艺要点

| 项目 | 要求 |
|---|---|
| 烙铁温度 | 300 ~ 340℃（无铅锡 350℃）。温度不够 = 冷焊 = 虚焊 |
| 顺序 | 先低后高、先小后大。先焊电阻/排针，最后焊电源端子 |
| 镀锡 | **所有线头焊接前必须先镀锡**，尤其是多股软线，不镀锡压接后容易散股短路 |
| 助焊剂 | 必用。焊完用酒精擦干净残留，否则长期吸潮漏电 |
| 热缩管 | 每个焊点都要套。**电源正极必须先套热缩管再做下一个焊点** |
| 虚焊检查 | 焊完用万用表蜂鸣档逐点量通断，再轻拽一下线看会不会掉 |
| 桥接检查 | 排针密集处用放大镜检查有没有锡桥。相邻引脚短路 = 功能乱七八糟但不一定烧芯片，最难排查 |

## 4. 分步上电检查清单（照着做，别跳步）

| 步骤 | 操作 | 合格标准 | 不合格怎么办 |
|---|---|---|---|
| 1 | **不插 STM32**，只接电池 + 继电器 + 降压模块 | 万用表量 5V 输出 = 5.0V ± 0.2V | 量输入电压；降压模块电位器可调 |
| 2 | 断电，按断电遥控器 | 5V 输出变 0V；**再按一次能恢复** | 恢复不了 = 1.3 坑 1（继电器取电位置错了） |
| 3 | 插上 STM32（不接电机舵机） | 板载 LED 按 1Hz 慢闪；串口有 `==== CRTC2026 ROBOT-x BOOT ====` | 没输出 = 查 TX/RX 波特率 115200；查供电 |
| 4 | 接 PS2 接收器 | 串口 `L(  x,  y)` 行里摇杆数据会动；推摇杆有反应 | 一直 0 = DI/DO 反了（2.4） |
| 5 | 接 1 个 SG90 | 按方向键微调，舵机跟着动 | 舵机抖 = 5V 不够（换更粗的 5V 线） |
| 6 | 接 4 个舵机 | 同时动时 STM32 不复位 | 复位 = 5V 塌陷，见 4.1 |
| 7 | **架空**，接 1 个电机 | 推摇杆该轮转 | 不转 = nSLEEP 悬空；转反 = `MOTOR_x_DIR` 取反 |
| 8 | 接 4 个电机 | 见 `docs/调参指南.md` 的方向标定 | 见调参指南 |
| 9 | 落地，慢速试 | 见调参指南 | |

### 4.1 舵机一动单片机就复位的解决办法（按优先级）

1. **5V 线加粗**：杜邦线的线芯只有 0.2mm² 左右，1A 就掉 0.5V 以上。换成 0.5mm² 硅胶线。
2. **加电容**：在 5V 与 GND 之间并一个 **470μF / 16V 电解电容** + 一个 0.1μF 瓷片，装在舵机汇流点。这一颗电容能解决一半的"莫名复位"。
3. **软件限速**：`config.h` 里 `SERVO_SPEED_DPS` 调到 120（舵机慢一点，电流峰值低）。
4. **错峰**：`arm.c` 的序列器已经保证同一时刻只有一个舵机在动，不要绕过它直接写比较寄存器。
5. **独立供电**：极端情况下给舵机单独一路降压（注意：这仍然是"一个电池、一个输出接口"之后的分支，不违规）。

## 5. 常见故障速查表

| 现象 | 最可能的原因 | 排查顺序 |
|---|---|---|
| 电机一个都不转 | DRV8833 的 nSLEEP 悬空 | 量 nSLEEP 是否为高电平 |
| 电机抖但不转 | PWM 频率不对 / 占空比在死区内 | 量 PB6 是否有 10kHz 方波；调大 `MOTOR_DEADZONE` |
| 驱动芯片迅速发烫 | AO1/AO2 短路，或 VM/GND 反接 | 立刻断电，量输出脚对地电阻 |
| 舵机只在一个方向能动 | 信号线接触不良 | 换线；舵机三根线里棕色/黑色是 GND |
| PS2 一直连不上 | DI/DO 反了 / VCC 电压不对 | 对调 PA6/PA7；量接收器 VCC |
| 手柄偶尔断连 | 手柄没电 / 接收器天线被金属底盘遮住 | 把接收器立起来，远离电机和电池 |
| 车一给油门就往一边偏 | 左右轮 `MOTOR_DEADZONE` 有效值不一致 | 调 `MOTOR_LEFT_TRIM` / `MOTOR_RIGHT_TRIM` |
| 一开电机串口就全是乱码 | 电机干扰 / 没共地 | 确认所有 GND 连在一起；电机线加磁环或绞双绞 |
| 电池很快没电 | 某处短路 / 舵机堵转 | 摸哪里发烫；舵机有没有被结构卡死 |
| 一上电继电器就跳 | 继电器取电接在 OUT 后面了 | 见 1.3 坑 1 |
