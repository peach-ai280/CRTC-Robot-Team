## 一、我们想做一台什么样的车

两台**一模一样的四轮麦轮小车**，全向移动，靠 PS2 无线手柄操作。

- **1 号机**：从启动区的高台直接走桥上中央高地，抢中央的**黄色能量核心**（4 分）。
- **2 号机**：在地面扫 18 个**白色能量单元**（1 分/个）。
- **不想去爬坡**：麦轮在 26.6° 的坡上会打滑，我们判断收益期望是负的。
- **半自动靠"机械对中"**（V 型口 + 微动开关），不靠视觉。
  理由写在了 `01`：对中的失败模式是"没对准"（无害，重来一次就行），
  视觉的失败模式是"对准了错的目标"（有害，扣时间还可能撞车）。

## 三、我们做到哪一步了（截至 2026-10-08）

分成三档说，不混在一起。

### 3.1 已经跑通、有实测证据的

| 项 | 证据 |
|---|---|
| 电脑上的开发环境 | STM32CubeIDE 2.2.0 + arm-none-eabi-gcc 14.3.1 + 烧录器 STM32_Programmer_CLI + ST-LINK 驱动，**全部实跑通过** |
| 自己写的构建脚本 | `python tools/build.py ps2` 出固件：`text 19140 / data 468 / bss 3052` |
| **SWD 烧录链路** | `python tools/flash.py check` 实测返回：`Device ID 0x410`、`NVM 128 KBytes`、`Voltage 3.21V` |
| 仓库 | git 建好，首次提交 283 个文件已推到 GitHub，编译产物已用 `.gitignore` 排除 |

> `Voltage 3.21V` 这一行说明 ST-LINK 确实在给板子供电、芯片被正常识别 ——
> 整条"电脑 → ST-LINK → SWD → 芯片"的路是通的。**这是我们目前最实的一个进展。**

### 3.2 代码写完了，但还没上真车验证

固件是一个模块化的工程，下面这些都是**代码完成 + 离线仿真跑过**，但**没有在装了电机的真车上跑过**：

- 底盘全向运动（麦轮逆解 + 整体归一化限幅）
- 防滑四件套（加速度斜坡、死区补偿、起步助力、高速限自转）
- DRV8833 双路电机驱动（PHASE/ENABLE 接法）
- PS2 手柄 SPI 通信（含掉线保护）
- 舵机机构序列器、半自动一键宏、全自动调度器

> 我们另外写了一套 **C++ 版**放在 `cpp/`，能在**电脑上直接跑**（不用插板子）来验证参数。
> 一套 C 给比赛用，一套 C++ 用来学逻辑、离线验算，两套的参数必须同步改。

### 3.3 只有设计、还没动手的

- **3D 打印件**：模型和 STL 生成好了（25 个结构件 + 14 个外观件），**一件都还没打**。
- **整车装配**：没开始。车架、甲板、储仓、机械臂都还是模型。
- **机构实测**：夹爪开口、大臂高度、储仓能不能真装下 3 块方块 —— 都得等打印件到手才能验。
- **中期考核视频**：没拍。

## 五、为什么我们先把力气花在电控上

三条理由，都是很实际的：

1. **电控是唯一不依赖别人的事。** STM32、ST-LINK、PS2 都在我们手上，插上电脑就能干；
   而机械那边要在 3D 打印件到手、车装起来之后才能往下走。所以先做电控，是把能提前的活提前做。
2. **电控是全队最容易卡住的一环。** 我们是新生，之前谁都没碰过单片机。
   手柄连不上、烧不进去、电机不转 —— 这些坑没人能替我们踩。
3. **底盘是所有动作的地基。** 不管后面做夹爪还是做全自动，车动不起来一切都是空的。

## 七、关于这份文档的三点说明

### 7.1 "设计值"和"实测值"我们分开放

`02`、`09` 里凡是尺寸、重量、耗时这类数字，**如果是从模型算出来的，就标"设计值"**；
**只有拿尺子/秤量过的才叫"实测"**。中期提交前我们会把"实测"那一列全部量一遍填上，
视频里也会拍到尺子读数。**不会把算出来的数当成量出来的交上去。**

### 7.2 遇到的坑，我们都留着了

写文档的时候我们把"哪里卡住了、怎么试出来的"都记下来了 —— 比如
PS2 调了三个小时最后发现是 DI/DO 接反、DRV8833 的 nSLEEP 悬空导致电机完全不转、
舵机一动单片机就复位。这些"翻车记录"我们没删，因为过程本身才是这份日志要看的东西。

### 7.3 用了多少别人的东西，全写在 `开源项目说明.md`

手册要求"引用了开源项目要在文档里完整说明"。我们**单独写了一篇**，逐条列清楚：
哪些代码是我们自己写的、参考了谁的公开资料、用的工具各是什么许可。
**这一篇请务必看。**
