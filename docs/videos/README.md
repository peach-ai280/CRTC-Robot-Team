# 调试与演示录像

三段都是比赛前在室内瓷砖地面上用手机直接录的，原声没剪。之所以留着现场对话，是因为它比配乐更能说明当时在试什么、试到哪一步。

先说一个实际情况：GitHub 的网页对 mp4 只给下载，不给播放器。所以每段下面配了一张动图，打开页面就能看到车在动；要看带声音的完整版，点文件名下载。动图是从原片里截的几秒，不是整段。

---

## 01 第一次成功平移

8 秒。麦轮第一次做出平移动作。画面里那句「刚刚你是怎么按的」，就是当时我们还没搞清哪个摇杆管平移。

![第一次成功平移](../images/preview-01.gif)

## 02 底盘全向动作演示

47 秒。连续推摇杆，看前后、左右平移和转向的合成效果。对话里提到「舵机还没到」，那会儿取块机构还没装上。

## 补充说明

- 三段对应的固件是 `firmware_v2`，麦轮解算与限幅的代码在 `firmware_v2/src/robot_control.c`。
- 设计思路写在 [`docs/03_底盘运动与麦轮防滑.md`](../03_底盘运动与麦轮防滑.md)，踩坑过程另有一份第一人称的复盘在 [`docs/实践记录_底盘与电控.md`](../实践记录_底盘与电控.md)。
- 视频为 1280×720、H.264 编码、MP4 封装，手机和电脑都能直接打开。原片是手机拍的 HEVC，部分播放器不认，入库时转过一次码。
