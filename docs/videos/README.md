# 调试与演示录像

三段都是比赛前在室内瓷砖地面上用手机直接录的，原声没剪。之所以留着现场对话，是因为它比配乐更能说明当时在试什么、试到哪一步。

视频为 1280×720、H.264 编码、MP4 封装，浏览器和手机都能直接打开。原片是手机拍的 HEVC，部分播放器不认，这里转过一次码。

| 文件 | 长度 | 内容 |
|---|---|---|
| [`01-第一次成功平移.mp4`](01-第一次成功平移.mp4) | 8 秒 | 麦轮第一次做出平移动作。画面里那句"刚刚你是怎么按的"，就是当时没搞清哪个摇杆管平移 |
| [`02-底盘全向动作演示.mp4`](02-底盘全向动作演示.mp4) | 47 秒 | 连续推摇杆，看前后、左右平移和转向的合成效果。对话里提到"舵机还没到"，那会儿取块机构还没上 |
| [`03-原地转弯测试.mp4`](03-原地转弯测试.mp4) | 41 秒 | 试原地自转。这一段整车导线还全堆在洞洞板上没有整理，是没做线束之前的状态 |

三段对应的固件是 `firmware_v2`，麦轮解算与限幅的代码在 `firmware_v2/src/robot_control.c`，思路和踩过的坑写在 `docs/03_底盘运动与麦轮防滑.md`，踩坑过程另有一份第一人称的复盘在 `docs/实践记录_底盘与电控.md`。

封面图取自各段中间帧，放在 `docs/images/video-0X-cover.jpg`。
