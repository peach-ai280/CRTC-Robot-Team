# 方块携带与储仓

## 功能描述

满足基础功能考核里的两条：

- **方块携带（单一）**：把地面静止的 30mm 方块（V1.4）从"非携带"变成"携带"
- **方块携带（多项）**：**在保持第一块携带状态下**，再让第二块变成携带状态

这两条的分值逻辑是"完成的队伍平分 100 分"，也就是说**做的人越少你分越高**。
多项那条明显更难，是拉开差距的地方。

---

### 2026-09-16 · "携带"的判定要抠准

手册 4.3 对"携带"的定义：

> 物体与机器人接触且在重力环境下沿**任意方向**（包括前后、左右和上下）
> 均可跟随机器人运动即视为该物体被机器人携带。

三个关键词：

1. **任意方向**：不只是"不掉下去"，还包括左右横移、急停、加减速
2. **重力环境下**：翻过来看也不行 —— 也就是如果你的储仓口朝上，
   车翻了方块掉出来就不算（但车翻了本来就输了，所以实际只看正常姿态）
3. **接触**：必须真的贴着车体机构

⚠️ 判定节点是**比赛结束时**。所以"中途掉了又捡回来"不算问题，
关键是**终局哨响那一刻方块在车上**。

### 2026-10-08 · 储仓 v1：急停时方块滚出来了

**现象**：装了 2 个方块，车正常跑没问题，一急停（松摇杆）前排的方块就滚出来了。

**原因**：`MOTOR_IDLE_BRAKE = 1` 用的是"双高刹车"，减速度很大
（`CHASSIS_ACC_DOWN = 6.0`），方块惯性大于静摩擦就往前滚。

**解决（两个一起上）**：

1. **储仓前低后高 5°**：方块进去后靠重力贴到最里侧。
   注意是**前低后高**（车头那侧低）—— 这样刹车时惯性把方块往"高处"推，
   重力又把它拉回来，形成自锁。反过来（前高后低）会一刹车就滚出来。
2. **顶部单向挡板**：3 片，M2.5 轴铰接，只能向内翻。
   方块被前铲推进来时顶开挡板，进去之后挡板自重落下。

### 2026-10-09 · 挡板自重不够：加配重

**现象**：加了挡板之后，颠簸路段挡板会被震开，方块还是能跳出来。

**原因**：PLA 挡板只有 2.4g，自重力矩太小，恢复不到位。

**解决**：在挡板背面贴一小片**双面胶 + 一个小螺母（M4，约 1.5g）**做配重。
配重让挡板闭合力矩提高约 60%，颠簸时不再自己弹开。

（这是个很土但很有效的办法。正式的改进是把挡板改成 3mm 厚，
但我们不想为一个小件再跑一次打印。）

### 2026-10-09 · 多项携带实测

按考核要求做的演示序列：

```
1. 前铲放下，慢速接近方块 A（地面静止）
2. 对中限位触发 → 一键宏 → 夹紧 → 抬起 → 前铲兜入储仓格 1
3. 车体后退，确认 A 已在车上（此时 A 处于"携带"状态）
4. 转向方块 B，重复
5. 两块都在储仓内 → 车体做前进/后退/横移/急停各 2 秒
6. 全程方块未脱离 → 判定"多项携带"达成
```

### 2026-10-11 · 为什么储仓只做 3 格而不是更多

| 格数 | 储仓长 | 能带 | 问题 |
|---|---|---|---|
| 2 | 92mm | 2 块 | 考核刚够，实战太少 |
| **3** | **138mm** | **3 块** | 车长 236mm，储仓占 138mm，还有 90mm 给前铲和夹爪 ✓ |
| 4 | 184mm | 4 块 | 储仓太高导致重心上移（第 4 格要叠上去），且车头机构没地方放 |

另外算了一下**收益边际**：场上 18 个白块，两台车各带 3 块 = 6 块 = 9 分（半自动）。
再往上堆格数，重心升高带来的打滑/翻车风险 > 多带 1 块的收益。

**结论：3 格是当前约束下的最优解。**

### 2026-10-13 · 备用方案：车顶"粘"一块

如果储仓来不及做或者挡板不可靠，还有一个土办法：
在车顶平板上贴一片**双面胶 / 魔术贴的毛面**。方块压上去就会被粘住，
满足"任意方向跟随运动"的判定。

优点：零机构、零舵机、失败率极低。
缺点：只能带 1~2 块，而且取下来麻烦（比赛中我们不打算取下来，一直带到终局）。

我们把它作为**保底方案**，如果储仓在 10-15 前调不稳就切这个。
（规则里没有禁止粘合剂；手册禁止的是"未干胶体等粘性液体"，双面胶不在此列。）

### 2026-10-10 · ★★★ 储仓换向 + 整体前移 + 取消斜底（本节 138×56×50 那套作废）

**为什么改**：机械臂改成"收起时朝正后方平躺"之后，以回转轴 `AB_AX = 106` 为圆心、
水平伸出 `18 + 105 = 123mm`，**爪子中心落在 `x = 106 − 123 = −17`**。
而旧储仓放在车尾 `x ∈ [−118, −18]`，爪的**两根手指**（`x ∈ [−36,−30]`、`[−4, 2]`）
正好**扎进储仓最后一列方块上方 8mm —— 撞了 2 格**（位置 (2,1) 和 (2,2)）。
这是用 `tools/check_arm_clearance.py` 数值复算抓出来的（最早靠看图纸判断成"不相交"，
因为只比了高度、忽略了爪的宽度）。

**三条修法一起做（缺一条都不行）**：

| | 改法 | 效果 |
|---|---|---|
| a | 储仓**整仓前移**到 `x ∈ [−32, +68]`（原 `BIN_X0 = −118`） | 爪停靠点 −17 落进仓内 |
| b | 中间 4 根立柱从 `x = ±4` 挪到 **`x = −45 / +78`** | 让出甲板中段（最大无支撑跨距 120mm，3N 下垂 ≈0.05mm，可忽略） |
| c | 储仓**最后一列中两排刻意留空**（`BIN_SKIP = ((0,1),(0,2))`） | 那两格就是爪的停车位兼投料口 |

复算结果 **0 干涉**。

**★ 尺寸与布局换了向，参数全部更新**：

| 项目 | 旧（作废） | **新（现行）** |
|---|---|---|
| 外廓 | 138 × 56 × 50（长×宽×高，车尾竖排 3 格） | **100（沿车长 x）× 136（沿车宽 y）× 52（高）** |
| 内部排列 | 3 格 × 1 排 | **3 列（列距 31，沿 x）× 4 排（沿 y）= 12 位** |
| 内腔 | 单格净内宽 42 | **94 × 130** |
| 装车位置 | 车尾 `x ∈ [−118, −18]` | **`x ∈ [−32, +68]`、`y ∈ [−68, +68]`（甲板中段）** |
| 有效容量 | 3 块 | **12 位，最后列中两排留空 → 实装 10 块**（随车 10 + 爪里还能夹 1） |
| 底板 | **前低后高 5°** | **平放**（★ 5° 斜底是无效设计：5° < PLA 之间约 19° 的摩擦角，方块根本滑不动） |
| 减震 | 无 | **垫 3mm EVA / 鼠标垫**（后两列投料落差 100~120mm，必须减震；顺带解决急停窜动） |
| 仓壁 | 56 宽侧板 | `13_bin_side`（100×52×3）×2 + `12_bin_floor`（100×136×3） |

**★ 换向后为什么容量反而大了**：旧方案是"沿车长竖着排 3 格"，格子少还占满车尾；
新方案把储仓**横过来**、沿车宽方向排 4 排，每排又沿车长排 3 列，
于是 12 位只占 100mm 车长。**换向是为了给平躺的机械臂让位** —— 这是被动改、但结果更好。

**★ 投料落差**：爪停靠点 `x = −17` 正在储仓最后一列（`x ∈ [−28.5, 1.5]`）正上方，
张口时方块从 z≈113 掉到仓底 91.5，**落差只有 22mm**，是全仓最温和的投料位。
另两列（x = 17.5 / 48.5）要靠摆角 48°/68° 才能对准，落差 100~120mm → 所以必须垫 EVA。

**★ 顶部单向挡板（`15_bin_flap`）与配重那两条仍然有效**（10-08 / 10-09 的结论不变）。

**★ 待复核**：`13_bin_side` 上隔板榫槽的位置随储仓换向后是否还能对上
（隔板 `14_bin_divider` 是 130×46×3）。
