## 三句话看懂我们的机器人

1. **两台一样的 4 轮麦轮车**（236 × 162 × 148 mm，**约 1076 g**，全部远低于规则上限）。
2. **1 号机走桥**抢中央高台的黄色能量核心（4 分 × 1.25 = 5 分），
   **2 号机在地面**扫 18 个白色能量单元（1 分 × 1.5 = 1.5 分/个）。
   不走坡道 —— 麦轮在 26.6° 坡上会打滑，收益期望为负。
3. **半自动靠机械对中**（V 型口 + 双微动开关）而不是视觉，
   因为对中的失败模式是"没对准"（无害），视觉的失败模式是"对准了错的目标"（有害）。

## 技术栈与关键参数

| 项 | 值 |
|---|---|
| MCU | STM32F103C8T6 @ 72MHz，HAL + CubeIDE |
| 底盘 | 4 × TT 马达(1:48) + 4 × 60mm 麦轮，轴距 180 / 轮距 136 mm |
| 驱动 | DRV8833 ×2（PHASE/ENABLE 接法），PWM 10kHz |
| 舵机 | MG995 ×1（大臂）+ SG90 ×3（夹爪/前铲/备用），PWM 50Hz |
| 遥控 | PS2 无线手柄，SPI 模式 3，281kHz |
| 电源 | 2 × 18650 串联（7.4V）→ 无线继电器 → 电机直供 + 5V 降压 |
| 控制周期 | 底盘 5ms / 舵机 10ms / 日志 200ms |
| 半轴距 / 半轮距 / 轮半径 | 0.090 / 0.068 / 0.030 m |
