## 关于文档规范（对照手册 4.3.1）

我们按手册要求组织文档，逐条对照如下：

| 手册要求 | 我们的做法 |
|---|---|
| 以 `.md` 格式提交 | 全部为 Markdown |
| 按设计进度**从早到晚**组织 | `docs/工程日志.md` 与各分册均按推进顺序排列 |
| **一个机器人功能 = 一个板块**，以**具体功能（H2 标题）+ 功能描述与开发历程**（正文）构成 | `docs/工程日志.md` 是主日志，每节 H2 即一个功能，正文分「功能描述」「开发历程」 |
| 每篇文档由**若干**上述板块组成 | 主日志含 11 个功能板块 |
| 用了开源项目须在**文档末尾完整说明** | 见 `docs/开源项目说明.md`，主日志末节也做了指引 |
| 仓库名用队伍名称的**英文/拼音** | `CRTC-Robot-Team`（Robot Mobilization） |
| 所有文档放在仓库根目录的 **`docs/`** 文件夹 | 根目录只留本 README，其余全在 `docs/` |

## 三句话看懂我们的机器人

1. **两台一样的 4 轮麦轮车**（车体 236 × 162 × 148 mm；装收集铲后整车长 **283 mm**，
   红线 290 —— **只剩 7mm，是全车最紧的一条**）。
2. **1 号机走桥**抢中央高台的黄色能量核心（4 分 × 1.5 = 6 分），
   **2 号机在地面**扫 18 个白色能量单元（1 分 × 1.5 = 1.5 分/个）。
   **不走坡道** —— 麦轮在 26.6° 坡上会打滑，收益期望为负。
3. **半自动靠机械对中**（V 型口 + 双微动开关）而不是视觉，
   因为对中的失败模式是"没对准"（无害），视觉的失败模式是"对准了错的目标"（有害）。

## 技术栈与关键参数

| 项 | 值 |
|---|---|
| MCU | STM32F103C8T6 @ 72MHz |
| 底盘 | 4 × TT 马达(1:48) + 4 × 60mm 麦轮，轴距 180 / 轮距 136 mm |
| 驱动 | DRV8833 ×2（PHASE/ENABLE 接法），PWM 10kHz |
| 舵机 | MG995 ×1（大臂）+ SG90 ×3（夹爪/前铲/备用），PWM 50Hz |
| 遥控 | PS2 无线手柄，SPI 模式 3，281kHz |
| 电源 | 2 × 18650 串联（7.4V）→ 无线继电器 → 电机直供 + 5V 降压 |
| 控制周期 | 底盘 5ms / 舵机 10ms / 日志 200ms |
| 半轴距 / 半轮距 / 轮半径 | 0.090 / 0.068 / 0.030 m |
