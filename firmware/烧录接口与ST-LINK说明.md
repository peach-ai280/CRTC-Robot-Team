# 烧录接口与 ST-LINK：到底要不要焊在车上

> 你问："是不是不需要 ST-LINK 这些东西，直接焊上去供电，后面直接往上面烧就行？"
> **这里有个必须纠正的误解**，搞错了会让你改不了代码。看下面。

---

## 一句话结论

**ST-LINK 不焊在车上，但车上必须留一个 4 针的口子给它插。**

```
ST-LINK  = 烧录器（像 U 盘一样的外设）   → 用完拔走，不属于车
SWD 排针 = 车上焊死的 4 根针（或一个插座）→ 永远留着，这是车的"充电口"
```

**类比**：ST-LINK 是数据线，SWD 排针是手机上的充电口。
你不会把数据线焊在手机上，但手机上没充电口就没法传文件。

---

## 为什么不能"焊上去供电就完事"

芯片里的程序是**烧进去**的，不是通电就有的。一台全新的 STM32 里是空的，
通上电它什么都不会做。必须有一次"把程序灌进去"的动作，这个动作只能靠 ST-LINK。

**而且你后面一定会反复改代码**——调死区、调舵机角度、改宏的时间参数，
每改一次就要重新烧一次。芯片可以擦写 **10 万次**，烧多少次都不坏，完全不用担心。

**所以：车上不留 SWD 口 = 以后每改一行代码都要把芯片拆下来焊回去。** 千万别这么干。

---

## 你要在车上留什么

### 4 根线（这就是 SWD 接口）

| 针 | 名字 | 接到 STM32 哪里 |
|---|---|---|
| 1 | **3.3V** | 芯片的 3V3 |
| 2 | **GND** | 地（和电池负极共地） |
| 3 | **SWDIO** | PA13 |
| 4 | **SWCLK** | PA14 |

> PA13 / PA14 是芯片**专门留给调试的引脚**，不占用你控制电机舵机的那些口，放心用。

### 两种留法，选一种

**A. 焊 4P 排针（推荐）**
买一根 4 针的排针（2.54mm 间距，几毛钱），焊在板子边上一个**手能碰到的位置**，
别被电池、电机、储仓挡住。用完 ST-LINK 拔掉，比赛时留着也不碍事（重 1 克）。

> ⚠ 排针一定要**朝外**、**朝上**或**朝侧面**，不要朝下贴着装底盘那面，
> 否则装完车就摸不到了。

**B. 用最小系统板（如果你们买的是这种，什么都不用焊）**

如果你买的是那种蓝色的小板子（俗称"蓝药丸" / "STM32F103C8T6 最小系统板"），
**它上面已经有一排 4P 的 SWD 排针了**，通常是板子窄边上的那 4 个针。
直接拿杜邦线插上去就行，一个焊点都不用动。

```
      蓝药丸俯视
   ┌──────────────┐
   │              │
   │   [芯片]     │
   │              │
   └───┬──┬──┬───┘
       4针 SWD     ← 就是这里，标着 3V3 / GND / SWIO / SWCLK
```

## ST-LINK 怎么买、怎么接

### 买哪种

淘宝搜 **"ST-LINK V2"**，**¥8~15** 的就行，别买贵的。
注意买带塑料壳的那种（里面是小电路板），别买裸板（容易短路烧掉）。

> ⚠ 淘宝上有种叫 **"ST-LINK V2 升级版 / V2.1"** 的，也能用，但引脚排列不一样，
> 接线前一定对一下针脚定义（看壳子上印的字）。

### 接线（4 根，别多接）

```
ST-LINK        →    你的板子
─────────────────────────────
3.3V           →    3V3
GND            →    GND
SWDIO          →    PA13 (SWIO)
SWCLK          →    PA14 (SWCLK)
```

**只接这 4 根。** 不要接 ST-LINK 的 5V。

### ⚠ 供电怎么给（这里最容易烧东西）

两种接法，**二选一，不要同时接**：

| 方案 | 怎么接 | 什么时候用 |
|---|---|---|
| **甲：ST-LINK 供电** | 4 根全接（含 3.3V），**车上电池断开** | 早期只测板子、没接电机时 |
| **乙：电池供电** | **3.3V 那根不接**，只接 GND/SWDIO/SWCLK，车上电池开着 | 车已经装好、要带电机调试时 |

> **为什么不能同时接**：两个电源并联会互相灌电流，轻则烧 ST-LINK，重则烧芯片。
> 这是新手烧片子的头号原因。

**推荐用方案乙**：烧录前把车架起来（轮子离地），电池开上，然后插 3 根线烧。
这样烧完直接就能看电机转不转，不用重新接线。

## 烧录的完整流程（记住这个顺序）

```
1. 车架起来（轮子离地，别让它跑了）
2. 电池断开 或 确认总开关在 OFF
3. 插 ST-LINK 的 4 根线（对一遍：3V3 / GND / SWIO / SWCLK）
4. ST-LINK 插电脑 USB
5. 敲：  python tools/flash.py check     ← 确认连上了
6. 敲：  python tools/flash.py motion    ← 烧底盘测试固件
7. 看到 "烧录成功" 后，拔掉 ST-LINK（或只拔 USB，线留着）
8. 开电池，开串口助手 115200，发 w 看轮子转不转
```

**改了代码之后**：重复 5~8 就行，第 1~4 步的线不用动。

## 比赛当天要带 ST-LINK 吗

**建议带。** 赛场上临时改参数很常见（地面摩擦不一样、场地光线不一样）。
SWD 口留着 + ST-LINK 放工具盒里，总共 20 克，能救命。

> 有队伍为了省那 1 克把排针拆了，结果赛场上改不了代码，只能干瞪眼。

## 常见翻车现场

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `flash.py check` 说"没找到设备" | 线没接对 / 没供电 / BOOT0 跳线错了 | 见 `构建烧录与测试.md` 的排查清单 |
| 能连上但烧录失败 | 芯片被读保护锁了 | CubeProgrammer 里做一次 "Full chip erase" |
| ST-LINK 摸着烫手 | 大概率两个电源同时接了 | **立刻拔掉**，检查是不是 3.3V 和电池同时供着 |
| 烧完了车没反应 | 程序没跑起来 / BOOT0 还在高电平 | BOOT0 跳到 0，复位一次 |
| 以前能烧，突然不行了 | 排针松动 / 杜邦线断了 | 拔插几次，换个杜邦线试试（杜邦线是消耗品） |
