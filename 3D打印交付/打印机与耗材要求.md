# 打印机与耗材：有什么要求？

> 一句话结论：**只要是一台普通的 FDM 打印机（打 PLA 的那种），床 ≥ 200×200mm，就能打。**
> 耗材买 **PLA+（增韧），1.75mm，两卷 1kg（一深一浅）**，大约 ¥100~160。
> 下面写清楚为什么，以及哪些情况要停下来问我。

---

## 0. 先确认一件事：你那台机器能不能打？

照这 4 条打勾，**全勾上就开工**，有一条不对就先别打：

| # | 检查 | 怎么确认 | 我们要求的下限 |
|---|---|---|---|
| 1 | **是 FDM 机**（喷头挤丝那种），不是光固化 | 看有没有一卷丝挂在机器上。有丝 = FDM ✅ | **必须是 FDM** |
| 2 | **打印床最短边 ≥ 170mm** | 看机器铭牌，或量平台 | 我们最大的结构件 128×162mm |
| 3 | **耗材直径 1.75mm** | 看机器上挂的料盘标签，或进料口 | 1.75mm（99% 的机器都是） |
| 4 | **热床能到 60℃** | 屏幕上看温度设置 | ≥ 60℃ |

> 常见机器对照：创想三维 Ender-3 / Ender-3 V2 / V3（220×220）✅、
> 拓竹 Bambu A1（256×256）✅、Bambu A1 mini（180×180）✅ 勉强够、
> Prusa MINI（180×180）✅、纵维立方 Anycubic Kobra（220×220）✅。
> **150×150 以下的迷你机打不了甲板**——别硬试，告诉我，我把甲板再切一刀分四段。

### ⚠️ 光固化机（LCD / SLA / DLP）绝对不能打这些件

学校创客空间如果有那种"用液体树脂、紫光照"的机器，**不要拿去打结构件**。三个致命问题：

1. **树脂件脆得像饼干**——比赛车会撞墙、会从 180mm 摔下来（规则明确要求跌落后不掉件），树脂件一撞就碎。
2. **床太小**——光固化机常见床只有 120×70mm，我们的甲板 162mm 根本放不进。
3. **会继续固化变形**——树脂件打完放几天会翘，孔位就变了。

光固化机适合打手办，不适合打结构件。

| **PLA+（增韧）** 亮色 | 1.75mm / 1kg，**橙**或**白** | 1 卷 | ¥50~80 | ④ 外观套件（最后打） |

**合计约 ¥140~180**（只买一卷深色的话 ¥60~90）。

### ⚠️ 关于预算，有句话要说清楚

`docs/09` 的成本表里 PLA 只记了 **¥15**——那是按"一卷 ¥60，我们只用掉约 1/4"算的**原料价**，
规则也是这么认定的（"以购买发票为准仅将其原料价格计入制造成本"）。

但**你实际掏的钱是整卷的价**：

```
官方物资表（已买）        ¥353
补买件（微动开关/线材等）  ¥62
────────────────────────────
小计                     ¥415   ← 这就是之前跟你说的数
+ 耗材（实际现金）       ¥100~160  ← 之前没算进来
────────────────────────────
实际现金支出             ¥515~575
```

**报销上限 ¥400，超出部分要自付。** 想压下来就**先只买一卷深色**（¥50~80），外观件那卷等中期考核通过后再说。

### 为什么是 PLA+ 而不是普通 PLA

| | 普通 PLA | **PLA+（也叫 PLA Pro / 增韧 PLA）** |
|---|---|---|
| 价格 | ¥40~60 | ¥50~80（贵 10 块） |
| 刚度 | 够 | 差不多 |
| **抗冲击** | **脆，摔一下就裂** | **韧很多，摔了弹得回来** |
| 打印难度 | 简单 | 一样简单（温度高 5~10℃） |

比赛车会撞墙、会被撞、要过 180mm 跌落测试。**这 10 块钱差价是最值的保险。** 买它。

### 品牌怎么选

**别买 9.9 包邮的杂牌**——丝径忽粗忽细会堵头，堵一次你就要拆喷头半小时。

够用且常见的：三绿 SUNLU、易生 eSUN、Polymaker、创想三维 Creality、拓竹 Bambu。
按 ¥50~80/kg 这个价位买就行，不用追贵的。

### 两种颜色怎么用

单色打印机也能做出双色效果——**分两盘打，不要中途换料**：

```
结构件（①②③）→ 深灰或黑色    耐脏、显专业、划痕不明显
外观件（④）    → 橙色或白色    场上好认，队友一眼能找到自己的车
```

⚠️ 颜色只影响好不好看，**不影响能不能跑**。如果只买得起一卷，就买深色一卷，全打深色，外观件以后再说。

## 2. 买多少够？（算给你看）

我们实测：

```
50 个件，实体总重       324 g
+ 25% 废品/裙边/支撑     ≈ 405 g
+ 备件批次⑤（多打一份）  ≈  25 g
────────────────────────────────
实际耗材消耗             ≈ 430~480 g
```

**一卷 1kg 够打完全部。买两卷是因为**：

1. 你要打两种颜色（深色一卷 + 亮色一卷）
2. **新手第一次打必定会废几件**——翘边、堵头、取件掰断。留 30% 余量心里不慌
3. 万一设计要改（比如你量完底板发现孔位要挪），重打几个大件就吃掉半卷

> 一卷 1kg 的丝大约能打 330 米。我们全部件加起来用不到半卷，余量很足。

## 3. 打印机侧的要求（给操作的同学看）

| 项 | 要求 | 不达标的后果 |
|---|---|---|
| **喷嘴直径** | **0.4mm**（标配） | 0.2 太慢（一个甲板 8 小时）；0.6+ 打不出 M3 孔的细节 |
| **喷嘴温度** | PLA：200℃（第一层 205）；PLA+：205~215℃ | 温度低了层间粘不住，一掰就分层 |
| **热床温度** | 60℃（第一层 65℃） | 低于 55℃ 大件会翘边脱落 |
| **首层速度** | 20~25 mm/s | 快了粘不住床 |
| **冷却风扇** | **首层关，之后 100%** | 首层开风扇 = 必翘 |
| **床要调平** | 打印前必须做 | 这是新手 80% 失败的原因 |

> 这些参数在 `切片与打印操作手册.md` 第 4 节有完整版，照抄即可。

## 4. 三个新手必踩的坑（提前说，省两小时）

**① PLA 怕热。**
60℃ 就开始软。打完的件**别放窗台晒、别放车里、别放在暖气片旁边**。夏天赛场如果暴晒，车会慢慢变形。这是 PLA 唯一的硬伤，没法解决，只能避开。

**② 层间结合是最弱的地方。**
3D 打印件是"一层一层叠"的，层与层之间的结合力比层内弱得多。所以**摆放方向决定强度**：

- ❌ 夹爪指竖着打 → 夹东西时正好从层缝裂开（我们第一版就这么废的）
- ✅ **平躺着打** → 受力方向和层纹平行，扛得住

手册第 3 节写了每个件该怎么摆，照着做。

**③ 孔径一定会缩。**
打印出来的 M3 孔实际会小 0.2~0.3mm，螺丝插不进。**这是正常的，不是设计错了。**
用 3mm 钻头手动扩一下就行，千万别以为"孔打小了"去改模型。

## 5. 环境要求（容易被忽略）

| 项 | 要求 |
|---|---|
| 桌面 | 机器要放**水平且稳固**，打印时会震，桌子晃会导致层错位 |
| 通风 | PLA 气味很小，但别在密闭宿舍打一整夜 |
| 电源 | 打印机功率 200~350W，别和电热水壶插一个插线板 |
| 人 | **前 5 分钟必须在旁边盯着首层**，翘边了立刻停，晚了就白打一整件 |

> 一个甲板要打 4~6 小时。**不要半夜开始打然后去睡**——半夜堵头/翘边，早上起来就是一坨废塑料。
> 白天开始打，中途看几次。

## 6. 你现在要做的（三步，10 分钟）

1. **看机器铭牌**，把型号告诉我（或拍张照片发我），我判断能不能直接打
2. **量一下床**（能打的最大方块边长），≥200mm 就没问题
3. **买耗材**：PLA+ 深色 1 卷 + 亮色 1 卷（急的话先只买深色一卷，够打完 ①②③）

> 如果你们实验室**已经有 PLA 丝**，先问一句是什么料、放了多久。
> **开封超过半年且没密封保存的 PLA 会受潮**，打出来表面起疙瘩、层间粘不住。
> 受潮的料 60℃ 烘 4 小时能救回来，或者直接买新的（一卷才 50 块，比重打一遍划算）。

## 附：如果床不够大怎么办

| 床尺寸 | 情况 | 怎么办 |
|---|---|---|
| ≥ 220×220 | 理想 | 直接打，一床能摆 3~5 件 |
| 180×180 | 能打 | 甲板正着放（128×162 都 < 180）✅，但一次只能摆 1~2 件，慢 |
| 150×150 | **打不了甲板** | 告诉我，我把甲板切成 4 段（现有是前后 2 段） |
| ≤ 120 | 别用这台 | 换机器 |

甲板为什么要分段：整块 236×162mm 超床，所以切成**两段各 128mm**，接缝处**重叠 20mm**（128 + 128 − 20 = 236）。
接缝下方垫 `03_deck_splice`（60×60 搭接板），**M3×8 螺丝从下往上穿**。这个件别漏打，漏了甲板就是两片。
